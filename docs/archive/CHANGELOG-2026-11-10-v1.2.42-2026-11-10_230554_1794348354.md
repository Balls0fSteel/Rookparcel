## 2026-11-10_154556_1794321956: Version 1.2.42: the GTK and Mac clients run on the VMs; two fixes found there

- **Asked by the owner** after 1.2.41: run the GTK and Mac windows of Statistics, Trackers and Run Program, which had only been compiled.
- **GTK, fixed (`crates/gtk/src/statistics.rs`):** Statistics opened again after being closed was a dead black window ("A window is shown after it has been destroyed"), and the program panicked at exit: the module kept a strong reference to the window, so GTK never destroyed it. It keeps a weak one now; the Close button takes the focus before the window shows, so no value starts selected.
- **Mac, fixed (`crates/cocoa/src/ui/target.rs`, `prefs/controls.rs`):** Tab in the Trackers box typed a tab character and the focus stayed, so the keyboard could not leave the box, which is what stores it. Tab and Shift-Tab move the focus now (the Preferences box only; Create Torrent's and Properties' boxes are as they were).
- **Xubuntu VM (Xvfb, GTK 4.22, real engine, scratch profile):** Statistics before Donate, 14 rows, Escape and Close, one window, live refresh (3.00 MB to 43.0 MB), kept over a restart. Trackers: greying, a junk line and an http address refused, Update Now against a closed port (failure shown, UI responsive) and against a real https list (20 trackers, the Logger's line, the cache file), two tiers stored and read back. Run Program: an empty line and an open quote refused; a real download of `it's a test & more; --delete.bin` from a loopback nox seeder, added through Add Torrent from URL, ran `/bin/sh args.sh ...` once with every argument whole, and not again after a restart; the typed trackers were on that download. Dark looks. Clippy `-D warnings` on Linux (1.99.1) clean.
- **macOS VM (Intel 15.8.2, console unlocked, real screen captures):** Statistics window (322 x 420, one instance, live), both pages in light and dark, greying, the five refusals shown in red with the last good value kept, a two-tier list stored and shown again, Update Now against a closed port and a real https list (20 trackers), and a real run: a script logged one "added" and one "finished" line for a torrent from a loopback nox seeder; Statistics then showed 293 kB downloaded. No exception in the logs.
- **Seen, not fixed (BACKLOG):** on the Mac a refused line is written to the ini while its check box is off (`pref_pages::live`; harmless until the box is ticked, when the check refuses it); in GTK the list's status line kept its text for the rest of the session after the web list was switched off; the Mac box's font is smaller than the fields'.
- **Validation:** fmt; clippy `-D warnings` for the workspace on Windows and the Mac crate (both darwin targets); the Mac crate's tests. **Not done:** a real window manager on Linux (stacking, title bars); pasting into the GTK box; `run.added` in GTK; Cmd+W on the Mac window; Retina and arm64; the Win32 client with a real transfer.
