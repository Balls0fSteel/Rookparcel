**Rookparcel 1.2.38** fixes a start that hashed every file again, quietens the Logger, adds Help > Donate, and puts a first-run guide into the Mac disk image, with a step-by-step [install guide](https://balls0fsteel.github.io/Rookparcel/install.html) on the website. It covers the development versions 1.2.31 to 1.2.37.

Rookparcel is a lean BitTorrent client in the spirit of µTorrent 2.2.1: small single-file binaries, a native look, low RAM and CPU use, and an interface that stays responsive with tens of thousands of torrents. The engine is our own Rust port of libtorrent-rasterbar 2.0.11; nothing is linked.

## New since 1.2.30

- **Fix: no full recheck after closing during a check.** Closing or pausing Rookparcel while a torrent still waited for its resume check saved that torrent as "pieces unknown", and the next start hashed every one of its files. Behind one long check that could be every torrent on the drive. The pieces are kept now. On every platform.
- **The Logger without tracker noise.** Trackers that do not answer no longer fill the Logger; public trackers fail all the time. Failed announces and scrapes still show on the Trackers tab, and `rookparcel-nox --verbose` prints them as before. One line is written when a private torrent has no tracker left that answers.
- **Help > Donate** in the Windows, Linux and Mac windows, and a Donate button in the Web UI. It opens the website's [donation page](https://balls0fsteel.github.io/Rookparcel/donate.html); nothing else is sent.
- **macOS: a first-run guide in the disk image.** `How to open Rookparcel.html` sits next to the app and shows how to get past Gatekeeper on macOS 15 and newer (System Settings > Privacy & Security > Open Anyway) and on macOS 11 to 14.
- **Website: an install guide.** [Step by step](https://balls0fsteel.github.io/Rookparcel/install.html) for the Windows installer and zip, AppImage, Flatpak, the plain binaries and the Mac app, with drawings of the warnings Windows and macOS show.
- **Windows: notes that were cut off.** In languages with longer texts, the notes in Preferences, the IP filter's status and some prompts ended mid-sentence. They now grow with their text.
- **Windows, dark mode:** lists no longer show column lines below the last row; the status bar shows its help text for menu items; the torrent list keeps no empty icon room in columns other than Name.
- **Linux: lower buttons and fields.** The GTK window's buttons, text fields and drop-downs are 26 to 28 px high in place of the theme's 34, closer to the Windows and Mac windows.

## Updating

- **Windows installer.** Rookparcel 1.2.5 and later offer the update themselves: Help > Check for Updates, then "Download and install". Settings and torrents are kept.
- **macOS.** Quit Rookparcel first, then drag the new `Rookparcel.app` to Applications over the old one.
- **Everything else.** Replace the program, the AppImage or the bundle as before. Settings and torrents are kept.
- **Remote control.** 1.2.38 speaks remote protocol 17, as 1.2.30 does; 1.2.5 to 1.2.29 speak 16. A GUI on a 1.2.30 daemon works, but its Logger shows no tracker lines.
- **From PaTorrent.** PaTorrent does not offer this update. Install Rookparcel by hand, as in [1.2.5's notes](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.38/docs/releases/1.2.5.md#coming-from-patorrent).

## First run

The website's [install guide](https://balls0fsteel.github.io/Rookparcel/install.html) shows these steps one at a time.

- **Windows installer.** Run the setup. It is not code-signed, so SmartScreen shows "Windows protected your PC": click More info > Run anyway. "Install for anyone using this computer" asks for administrator rights and shows "Unknown publisher". Settings and torrents are in `%APPDATA%\Rookparcel`.
- **Windows zip.** Unzip anywhere and start `rookparcel.exe`; SmartScreen warns as above. An empty `rookparcel.ini` next to the exe keeps settings and torrents beside it (portable mode).
- **macOS.**
  1. Open the disk image and drag `Rookparcel.app` to Applications.
  2. The app is ad-hoc signed and not notarised, so Gatekeeper refuses it the first time. The disk image's `How to open Rookparcel.html` has these steps too.
     - macOS 15 Sequoia and newer: double-click the app and click Done in the warning. Open System Settings > Privacy & Security, scroll to Security and click Open Anyway (offered for about an hour), then confirm with your password or Touch ID.
     - macOS 11 to 14: Control-click (or right-click) the app, choose Open, then click Open.
     - Or, also when macOS says the app "is damaged", run `xattr -dr com.apple.quarantine /Applications/Rookparcel.app` in Terminal.
  3. macOS may ask whether Rookparcel may find devices on local networks. Allow it for peers and a Rookparcel daemon on your own network; downloads from the internet work either way.

  Settings and torrents are in `~/Library/Application Support/Rookparcel/mac`.
- **Linux AppImage.** Run `chmod +x Rookparcel-1.2.38-x86_64.AppImage`, then start it. Without FUSE 2 on the system, start it with `--appimage-extract-and-run`. Settings are in `~/.config/rookparcel/gtk`, torrents in `~/.local/share/rookparcel/gtk`.
- **Linux Flatpak.** The bundle holds the application; the runtime comes from Flathub:

  ```bash
  flatpak remote-add --if-not-exists --user flathub https://dl.flathub.org/repo/flathub.flatpakrepo
  flatpak install --user Rookparcel-1.2.38-x86_64.flatpak
  flatpak run io.github.balls0fsteel.Rookparcel
  ```

- **Headless.** `rookparcel-nox run --webui 8080 --webui-pass PASS` starts the daemon with its Web UI and a qBittorrent-compatible Web API on port 8080. [DAEMON.md](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.38/docs/DAEMON.md) describes services: systemd, FreeBSD rc.d, `--daemon` and Windows, one per profile if you like. Your own Web UI themes go in `webui/themes` under its settings folder (`/config` in Docker).
- **Docker.**

  ```bash
  docker run -d --name rookparcel -p 8080:8080 -p 6881:6881 -p 6881:6881/udp -e ROOKPARCEL_WEBUI_PASS=choose-one -v rookparcel-config:/config -v /srv/media:/downloads ghcr.io/balls0fsteel/rookparcel-nox:1.2.38
  ```

  Then open `http://<host>:8080` and log in as `admin`. Without `ROOKPARCEL_WEBUI_PASS`, `docker logs rookparcel` shows a temporary password. Stop it with `docker stop -t 60 rookparcel`, so it has time to save its torrents.

## Known limitations

- Everything in [1.2.0's limitations](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.38/docs/releases/1.2.0.md#known-limitations), [1.2.5's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.38/docs/releases/1.2.5.md#known-limitations), [1.2.19's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.38/docs/releases/1.2.19.md#known-limitations), [1.2.21's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.38/docs/releases/1.2.21.md#known-limitations) and [1.2.30's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.38/docs/releases/1.2.30.md#known-limitations) still applies.
- **The first-run steps for macOS follow Apple's own description.** They were not tried on a real Mac of each macOS version; the drawings in the install guide show what to look for, not the exact windows.
- **Help > Donate and the new Logger line are machine-translated** in the languages other than English.
- **The lower GTK buttons were checked in GTK's default theme and Greybird** on one Xubuntu machine. Other themes and scaled displays were not tried.
- **Do not use it on private trackers yet.** The client ID `RP` is not whitelisted anywhere.

## Reporting problems

Open an [issue](https://github.com/Balls0fSteel/Rookparcel/issues) with your platform, the file you used and what happened. For a crash or a stuck torrent, include the Logger tab or `rookparcel-nox run --verbose` output. On a Mac, Console.app's crash report for Rookparcel helps too. For security problems, see [SECURITY.md](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.38/SECURITY.md).
