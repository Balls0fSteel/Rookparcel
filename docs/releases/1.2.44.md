**Rookparcel 1.2.44** adds Help > Statistics with all-time totals, trackers for new downloads, and Run Program on torrent events. It fixes a start that hashed every file again, quietens the Logger, adds Help > Donate, and puts a first-run guide into the Mac disk image, with a step-by-step [install guide](https://balls0fsteel.github.io/Rookparcel/install.html) on the website. It covers the development versions 1.2.31 to 1.2.43.

Rookparcel is a lean BitTorrent client in the spirit of µTorrent 2.2.1: small single-file binaries, a native look, low RAM and CPU use, and an interface that stays responsive with tens of thousands of torrents. The engine is our own Rust port of libtorrent-rasterbar 2.0.11; nothing is linked.

## New since 1.2.30

- **Help > Statistics.** What Rookparcel uploaded and downloaded in all its sessions and in this one, the share ratio, the data thrown away, the connected peers, the disk queue and the read cache. The all-time totals are counted for the program, not per torrent, so removing a torrent takes nothing away; an existing install starts from the sum of its torrents. In the Windows, Linux and Mac windows and the Web UI.
- **Trackers for new downloads** (Preferences > Advanced > Trackers). A list you type, a list read from an `https://` address once a day, or both, added after each new torrent's own trackers. Private torrents never get them, nor do torrents already in the list, ones you create or ones you import. The list on the web is only ever read as a list of tracker addresses, at most 200. Off at first.
- **Run Program** (Preferences > Advanced > Run Program). Starts a program of yours when a torrent is added or when one finishes downloading, with qBittorrent's codes `%N %L %F %D %Z %T %I %J %K` for the torrent's details. Off at first. Built with care for what went wrong elsewhere:
  - The program is started directly, without a command shell, and each code is filled in inside its own argument: a torrent's name can never become a command or a second argument.
  - A line that hands a code to a shell told to run a string (`cmd /c ... %N`, `powershell -Command`, `sh -c`) is refused; name the script itself instead (`powershell -File x.ps1 "%N"`, `/bin/sh /x/done.sh "%N"`, `"C:\x\done.bat" "%N"`).
  - In the Web UI the lines change only from a browser on the computer that runs `rookparcel-nox`, with the current password. A session from elsewhere neither changes nor reads them, the qBittorrent-compatible API ignores `autorun_*`, and a remote connection cannot carry them. A server with no local browser (Docker) needs `--webui-remote-run-program` on its command line.
- **Fix: no full recheck after closing during a check.** Closing or pausing Rookparcel while a torrent still waited for its resume check saved that torrent as "pieces unknown", and the next start hashed every one of its files. Behind one long check that could be every torrent on the drive. The pieces are kept now. On every platform.
- **Fix: `rookparcel-nox` applies its stored settings before the engine starts.** UPnP, NAT-PMP, the DHT and Local Peer Discovery switched off in the Web UI were on for the first moments of every start.
- **The Logger without tracker noise.** Trackers that do not answer no longer fill the Logger; public trackers fail all the time. Failed announces and scrapes still show on the Trackers tab, and `rookparcel-nox --verbose` prints them as before. One line is written when a private torrent has no tracker left that answers.
- **Help > Donate** in the Windows, Linux and Mac windows, and a Donate button in the Web UI. It opens the website's [donation page](https://balls0fsteel.github.io/Rookparcel/donate.html); nothing else is sent.
- **macOS: a first-run guide in the disk image.** `How to open Rookparcel.html` sits next to the app and shows how to get past Gatekeeper on macOS 15 and newer (System Settings > Privacy & Security > Open Anyway) and on macOS 11 to 14.
- **Website: an install guide.** [Step by step](https://balls0fsteel.github.io/Rookparcel/install.html) for the Windows installer and zip, AppImage, Flatpak, the plain binaries and the Mac app, with drawings of the warnings Windows and macOS show.
- **Windows: notes that were cut off.** In languages with longer texts, the notes in Preferences, the IP filter's status and some prompts ended mid-sentence. They now grow with their text.
- **Windows, dark mode:** lists no longer show column lines below the last row; the status bar shows its help text for menu items; the torrent list keeps no empty icon room in columns other than Name.
- **Linux: lower buttons and fields.** The GTK window's buttons, text fields and drop-downs are 26 to 28 px high in place of the theme's 34, closer to the Windows and Mac windows.

## Updating

- **Windows installer.** Rookparcel 1.2.5 and later offer the update themselves: Help > Check for Updates, then "Download and install". Settings and torrents are kept.
- **macOS.** Quit Rookparcel first, then drag the new `Rookparcel.app` to Applications over the old one.
- **Everything else.** Replace the program, the AppImage or the bundle as before. Settings and torrents are kept.
- **Remote control: update both ends.** 1.2.44 speaks remote protocol 18 (the statistics travel with it); 1.2.30 speaks 17. A 1.2.44 window does not connect to an older `rookparcel-nox`, nor an older window to a 1.2.44 one. The Web UI and the qBittorrent-compatible API are not affected.
- **Statistics start from your torrents.** The first start of 1.2.44 takes the sum of what the torrents in the list uploaded and downloaded as the all-time totals; torrents removed before the update are not in it.
- **From PaTorrent.** PaTorrent does not offer this update. Install Rookparcel by hand, as in [1.2.5's notes](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.44/docs/releases/1.2.5.md#coming-from-patorrent).

## First run

The website's [install guide](https://balls0fsteel.github.io/Rookparcel/install.html) shows these steps one at a time.

- **Windows installer.** Run the setup. It is not code-signed, so SmartScreen shows "Windows protected your PC": click More info > Run anyway. "Install for anyone using this computer" asks for administrator rights and shows "Unknown publisher". Settings and torrents are in `%APPDATA%\Rookparcel`.
- **Windows zip.** Unzip anywhere and start `rookparcel.exe`; SmartScreen warns as above. An empty `rookparcel.ini` next to the exe keeps settings and torrents beside it (portable mode).
- **macOS.**
  1. Open the disk image and drag `Rookparcel.app` to Applications.
  2. The app is ad-hoc signed and not notarised, so Gatekeeper refuses it the first time. The disk image's `How to open Rookparcel.html` has these steps too.
     - macOS 15 Sequoia and newer: double-click the app and click Done in the warning. Open System Settings > Privacy & Security, scroll to Security and click Open Anyway (offered for about an hour), then confirm with your password or Touch ID.
     - macOS 11 to 14: Control-click (or right-click) the app, choose Open, then click Open.
     - Or, also when macOS says the app "is damaged", run `xattr -dr com.apple.quarantine /Applications/Rookparcel.app` in Terminal.
  3. macOS may ask whether Rookparcel may find devices on local networks. Allow it for peers and a Rookparcel daemon on your own network; downloads from the internet work either way.

  Settings and torrents are in `~/Library/Application Support/Rookparcel/mac`.
- **Linux AppImage.** Run `chmod +x Rookparcel-1.2.44-x86_64.AppImage`, then start it. Without FUSE 2 on the system, start it with `--appimage-extract-and-run`. Settings are in `~/.config/rookparcel/gtk`, torrents in `~/.local/share/rookparcel/gtk`.
- **Linux Flatpak.** The bundle holds the application; the runtime comes from Flathub:

  ```bash
  flatpak remote-add --if-not-exists --user flathub https://dl.flathub.org/repo/flathub.flatpakrepo
  flatpak install --user Rookparcel-1.2.44-x86_64.flatpak
  flatpak run io.github.balls0fsteel.Rookparcel
  ```

- **Headless.** `rookparcel-nox run --webui 8080 --webui-pass PASS` starts the daemon with its Web UI and a qBittorrent-compatible Web API on port 8080. [DAEMON.md](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.44/docs/DAEMON.md) describes services: systemd, FreeBSD rc.d, `--daemon` and Windows, one per profile if you like. Your own Web UI themes go in `webui/themes` under its settings folder (`/config` in Docker).
- **Docker.**

  ```bash
  docker run -d --name rookparcel -p 8080:8080 -p 6881:6881 -p 6881:6881/udp -e ROOKPARCEL_WEBUI_PASS=choose-one -v rookparcel-config:/config -v /srv/media:/downloads ghcr.io/balls0fsteel/rookparcel-nox:1.2.44
  ```

  Then open `http://<host>:8080` and log in as `admin`. Without `ROOKPARCEL_WEBUI_PASS`, `docker logs rookparcel` shows a temporary password. Stop it with `docker stop -t 60 rookparcel`, so it has time to save its torrents.

## Known limitations

- Everything in [1.2.0's limitations](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.44/docs/releases/1.2.0.md#known-limitations), [1.2.5's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.44/docs/releases/1.2.5.md#known-limitations), [1.2.19's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.44/docs/releases/1.2.19.md#known-limitations), [1.2.21's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.44/docs/releases/1.2.21.md#known-limitations) and [1.2.30's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.44/docs/releases/1.2.30.md#known-limitations) still applies.
- **Run Program behind a reverse proxy.** A proxy or tunnel on the server itself (nginx, HAProxy, stunnel, an SSH tunnel) makes every visitor look like a browser on the same computer unless it adds `X-Forwarded-For`. Without that header, whoever reaches the proxy and knows the password can change the Run Program lines. For nginx: `proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;`.
- **Run Program and magnet links.** The "added" program runs about a second after a magnet link is added: before the torrent's details have arrived (`%N` is the link's name or the info hash, `%Z` is 0), before its Add dialog is answered, and also when that dialog is cancelled.
- **Run Program's shell check knows `cmd`, PowerShell and the Unix shells.** A code handed to another interpreter told to run a string (`wsl sh -c`, `env sh -c`, `busybox sh -c`) is not caught. `%C`, `%R` and `%G` are not there.
- **Trackers and Run Program need the Web UI in `rookparcel-nox`.** It keeps these settings with the Web UI's, so without `--webui` it uses neither. In a window connected to a remote daemon the two pages store values that do nothing; set them on the server.
- **A typed tracker line that is no tracker address is dropped without a message** when "Add these trackers" is off, in the Windows and Linux windows; more than 200 typed trackers are cut to 200.
- **Dates in the Web UI are UTC**, the Statistics' "counted since" and the tracker list's "downloaded" time among them.
- **The new pages, Statistics, Help > Donate and the new Logger line are machine-translated** in the languages other than English.
- **Not tried by hand:** Statistics, Trackers and Run Program on Apple silicon and Retina displays; the 1.2.44 fixes ran in tests, not again on the Linux and Mac test machines.
- **The first-run steps for macOS follow Apple's own description.** They were not tried on a real Mac of each macOS version; the drawings in the install guide show what to look for, not the exact windows.
- **The lower GTK buttons were checked in GTK's default theme and Greybird** on one Xubuntu machine. Other themes and scaled displays were not tried.
- **Do not use it on private trackers yet.** The client ID `RP` is not whitelisted anywhere.

## Reporting problems

Open an [issue](https://github.com/Balls0fSteel/Rookparcel/issues) with your platform, the file you used and what happened. For a crash or a stuck torrent, include the Logger tab or `rookparcel-nox run --verbose` output. On a Mac, Console.app's crash report for Rookparcel helps too. For security problems, see [SECURITY.md](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.44/SECURITY.md).
