**Rookparcel 1.2.30** makes the programs quieter when they have nothing to do. Our benchmark run of 1.2.29 found that it used more CPU while idle than 1.0.1 did; both causes are fixed. There is nothing new to see.

Rookparcel is a lean BitTorrent client in the spirit of µTorrent 2.2.1: small single-file binaries, a native look, low RAM and CPU use, and an interface that stays responsive with tens of thousands of torrents. The engine is our own Rust port of libtorrent-rasterbar 2.0.11; nothing is linked.

## New since 1.2.29

- **Fix: idle CPU after a start with many torrents.** Since 1.2.0, `rookparcel-nox` (and a Windows or Linux window with its Web UI switched on) read every torrent's stored metadata again after each start, a little each second, to learn which torrents are private. With 10,000 torrents that kept one core about 1% busy for over a minute. The flag is now kept with the torrent's saved state. In our test, idle CPU with 10,000 torrents is 0.12% of one core again (1.2.29: 0.33%, 1.0.1: 0.10%).
  - The first start after the update still does that pass once, for the torrents saved by an older version; later starts do not.
- **Fix: idle CPU with a very large list.** Since 1.1.40, local peer discovery looked at every torrent several times a second to count the running ones. With 100,000 stopped torrents the Windows program idled at 0.8 to 1.0% of one core; it is at 0.4% again. It now looks at the running torrents only.
- **Remote control:** a GUI and the `rookparcel-nox` it controls must both be 1.2.30 (remote protocol 17). An older one on either side is told so when it connects.

## Updating

- **Windows installer.** Rookparcel 1.2.5 and later offer the update themselves: Help > Check for Updates, then "Download and install". Settings and torrents are kept.
- **macOS.** Quit Rookparcel first, then drag the new `Rookparcel.app` to Applications over the old one.
- **Everything else.** Replace the program, the AppImage or the bundle as before. Settings and torrents are kept.
- **Remote control.** Update the GUI and the `rookparcel-nox` it controls together: 1.2.30 speaks remote protocol 17, and 1.2.5 to 1.2.29 speak 16.
- **From PaTorrent.** PaTorrent does not offer this update. Install Rookparcel by hand, as in [1.2.5's notes](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.30/docs/releases/1.2.5.md#coming-from-patorrent).

## First run

- **Windows installer.** Run the setup. It is not code-signed, so SmartScreen shows "Windows protected your PC": click More info > Run anyway. "Install for anyone using this computer" asks for administrator rights and shows "Unknown publisher". Settings and torrents are in `%APPDATA%\Rookparcel`.
- **Windows zip.** Unzip anywhere and start `rookparcel.exe`; SmartScreen warns as above. An empty `rookparcel.ini` next to the exe keeps settings and torrents beside it (portable mode).
- **macOS.**
  1. Open the disk image and drag `Rookparcel.app` to Applications.
  2. The app is ad-hoc signed and not notarised, so Gatekeeper refuses it the first time. Right-click (or Control-click) the app, choose Open, then click Open. If macOS offers no Open button, open System Settings > Privacy & Security and click Open Anyway. Or run `xattr -dr com.apple.quarantine /Applications/Rookparcel.app` in Terminal.
  3. macOS may ask whether Rookparcel may find devices on local networks. Allow it for peers and a Rookparcel daemon on your own network; downloads from the internet work either way.

  Settings and torrents are in `~/Library/Application Support/Rookparcel/mac`.
- **Linux AppImage.** Run `chmod +x Rookparcel-1.2.30-x86_64.AppImage`, then start it. Without FUSE 2 on the system, start it with `--appimage-extract-and-run`. Settings are in `~/.config/rookparcel/gtk`, torrents in `~/.local/share/rookparcel/gtk`.
- **Linux Flatpak.** The bundle holds the application; the runtime comes from Flathub:

  ```bash
  flatpak remote-add --if-not-exists --user flathub https://dl.flathub.org/repo/flathub.flatpakrepo
  flatpak install --user Rookparcel-1.2.30-x86_64.flatpak
  flatpak run io.github.balls0fsteel.Rookparcel
  ```

- **Headless.** `rookparcel-nox run --webui 8080 --webui-pass PASS` starts the daemon with its Web UI and a qBittorrent-compatible Web API on port 8080. [DAEMON.md](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.30/docs/DAEMON.md) describes services: systemd, FreeBSD rc.d, `--daemon` and Windows, one per profile if you like. Your own Web UI themes go in `webui/themes` under its settings folder (`/config` in Docker).
- **Docker.**

  ```bash
  docker run -d --name rookparcel -p 8080:8080 -p 6881:6881 -p 6881:6881/udp -e ROOKPARCEL_WEBUI_PASS=choose-one -v rookparcel-config:/config -v /srv/media:/downloads ghcr.io/balls0fsteel/rookparcel-nox:1.2.30
  ```

  Then open `http://<host>:8080` and log in as `admin`. Without `ROOKPARCEL_WEBUI_PASS`, `docker logs rookparcel` shows a temporary password. Stop it with `docker stop -t 60 rookparcel`, so it has time to save its torrents.

## Known limitations

- Everything in [1.2.0's limitations](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.30/docs/releases/1.2.0.md#known-limitations), [1.2.5's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.30/docs/releases/1.2.5.md#known-limitations), [1.2.19's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.30/docs/releases/1.2.19.md#known-limitations) and [1.2.21's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.30/docs/releases/1.2.21.md#known-limitations) still applies.
- **Dark mode on Windows uses parts of Windows that are not documented** (the same ones Explorer, Notepad++ and Chromium use). It was tried on Windows 11 at 100, 150 and 200 %, and switching live both ways; Windows 10 version 1809, the oldest it supports, was not. If a Windows build ever changes those parts, the program stays light and says so under the Theme box. The text boxes with several lines (the tracker lists) keep a light frame in dark; the drag image of a column header stays light.
- **The Web UI themes were tried in a desktop browser.** A real phone and Safari were not. A third-party theme is a CSS file the operator places in the settings folder; the page's content security policy keeps it from loading anything from elsewhere.
- **Do not use it on private trackers yet.** The client ID `RP` is not whitelisted anywhere.

## Reporting problems

Open an [issue](https://github.com/Balls0fSteel/Rookparcel/issues) with your platform, the file you used and what happened. For a crash or a stuck torrent, include the Logger tab or `rookparcel-nox run --verbose` output. On a Mac, Console.app's crash report for Rookparcel helps too. For security problems, see [SECURITY.md](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.30/SECURITY.md).
