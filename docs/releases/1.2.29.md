**Rookparcel 1.2.29** brings dark mode to the Windows program and themes to the Web UI. On Windows the window follows *Choose your mode* for apps by default, and Preferences can fix it light or dark; every window, dialog and icon follows. The Web UI has nine themes, a choice per server and per browser, and takes your own CSS files. The GTK app's drawn parts and icons follow a dark GTK theme correctly.

Rookparcel is a lean BitTorrent client in the spirit of µTorrent 2.2.1: small single-file binaries, a native look, low RAM and CPU use, and an interface that stays responsive with tens of thousands of torrents. The engine is our own Rust port of libtorrent-rasterbar 2.0.11; nothing is linked.

## New since 1.2.21

Versions 1.2.22 to 1.2.28 were development steps and were never released; this list covers them.

- **Dark mode on Windows.** Options > Preferences > UI Settings > **Theme**:
  - **System (light or dark)**, the default, follows Windows' Settings > Personalization > Colors > *Choose your mode* for apps, and changes with it while the program runs;
  - **Light** and **Dark** fix the colours whatever Windows says.
  - Everything follows: the title bar, menus, toolbar, the torrent list and its header, the categories, the detail tabs and their graphs, the status bar, every dialog (Preferences and the scheduler included), remote windows, and the icons, which come in a light and a dark set. Windows **High Contrast** always wins and keeps the system's colours.
  - Dark needs Windows 10 version 1809 or later; an older Windows shows a note under the Theme box and stays light. Message boxes, the file picker and the update download's progress bar stay the system's.
- **Web UI themes.** Preferences > UI Settings > **Theme** sets the page's look for everyone who opens it: System (light or dark), Light, Dark, Midnight, Slate, Solarized Dark, Solarized Light, High Contrast and Postal Rook. **Theme in this browser** keeps a choice on one device instead. Put your own `.css` files in the `webui/themes` folder under the settings folder (the [Web UI page](https://github.com/Balls0fSteel/Rookparcel/wiki/Web-UI) describes the 29 colour variables) and they appear in the lists.
- **GTK (Linux):** the progress bars, the piece map, the Blocks cells and the scheduler follow a dark GTK theme; the scheduler's Off cell takes the surface colour in every app. Dark is decided by the GTK theme (Adwaita-dark, Breeze-Dark, `gtk-application-prefer-dark-theme`, `GTK_THEME=Adwaita:dark`), not by the desktop's preference alone, which plain GTK 4 windows do not follow.
- **Fix (Windows):** "Alternate list background color" took effect only at the next start.

## Updating

- **Windows installer.** Rookparcel 1.2.5 and later offer the update themselves: Help > Check for Updates, then "Download and install". Settings and torrents are kept. The new Theme setting starts at System, so a Windows set to dark shows the program dark after the update; choose Light under UI Settings to keep the old look.
- **macOS.** Quit Rookparcel first, then drag the new `Rookparcel.app` to Applications over the old one.
- **Everything else.** Replace the program, the AppImage or the bundle as before. Settings and torrents are kept.
- **Remote control.** The remote protocol is unchanged (16), so 1.2.5 to 1.2.29 GUIs and daemons work with each other.
- **From PaTorrent.** PaTorrent does not offer this update. Install Rookparcel by hand, as in [1.2.5's notes](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.29/docs/releases/1.2.5.md#coming-from-patorrent).

## First run

- **Windows installer.** Run the setup. It is not code-signed, so SmartScreen shows "Windows protected your PC": click More info > Run anyway. "Install for anyone using this computer" asks for administrator rights and shows "Unknown publisher". Settings and torrents are in `%APPDATA%\Rookparcel`.
- **Windows zip.** Unzip anywhere and start `rookparcel.exe`; SmartScreen warns as above. An empty `rookparcel.ini` next to the exe keeps settings and torrents beside it (portable mode).
- **macOS.**
  1. Open the disk image and drag `Rookparcel.app` to Applications.
  2. The app is ad-hoc signed and not notarised, so Gatekeeper refuses it the first time. Right-click (or Control-click) the app, choose Open, then click Open. If macOS offers no Open button, open System Settings > Privacy & Security and click Open Anyway. Or run `xattr -dr com.apple.quarantine /Applications/Rookparcel.app` in Terminal.
  3. macOS may ask whether Rookparcel may find devices on local networks. Allow it for peers and a Rookparcel daemon on your own network; downloads from the internet work either way.

  Settings and torrents are in `~/Library/Application Support/Rookparcel/mac`.
- **Linux AppImage.** Run `chmod +x Rookparcel-1.2.29-x86_64.AppImage`, then start it. Without FUSE 2 on the system, start it with `--appimage-extract-and-run`. Settings are in `~/.config/rookparcel/gtk`, torrents in `~/.local/share/rookparcel/gtk`.
- **Linux Flatpak.** The bundle holds the application; the runtime comes from Flathub:

  ```bash
  flatpak remote-add --if-not-exists --user flathub https://dl.flathub.org/repo/flathub.flatpakrepo
  flatpak install --user Rookparcel-1.2.29-x86_64.flatpak
  flatpak run io.github.balls0fsteel.Rookparcel
  ```

- **Headless.** `rookparcel-nox run --webui 8080 --webui-pass PASS` starts the daemon with its Web UI and a qBittorrent-compatible Web API on port 8080. [DAEMON.md](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.29/docs/DAEMON.md) describes services: systemd, FreeBSD rc.d, `--daemon` and Windows, one per profile if you like. Your own Web UI themes go in `webui/themes` under its settings folder (`/config` in Docker).
- **Docker.**

  ```bash
  docker run -d --name rookparcel -p 8080:8080 -p 6881:6881 -p 6881:6881/udp -e ROOKPARCEL_WEBUI_PASS=choose-one -v rookparcel-config:/config -v /srv/media:/downloads ghcr.io/balls0fsteel/rookparcel-nox:1.2.29
  ```

  Then open `http://<host>:8080` and log in as `admin`. Without `ROOKPARCEL_WEBUI_PASS`, `docker logs rookparcel` shows a temporary password. Stop it with `docker stop -t 60 rookparcel`, so it has time to save its torrents.

## Known limitations

- Everything in [1.2.0's limitations](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.29/docs/releases/1.2.0.md#known-limitations), [1.2.5's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.29/docs/releases/1.2.5.md#known-limitations), [1.2.19's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.29/docs/releases/1.2.19.md#known-limitations) and [1.2.21's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.29/docs/releases/1.2.21.md#known-limitations) still applies.
- **Dark mode on Windows uses parts of Windows that are not documented** (the same ones Explorer, Notepad++ and Chromium use). It was tried on Windows 11 at 100, 150 and 200 %, and switching live both ways; Windows 10 version 1809, the oldest it supports, was not. If a Windows build ever changes those parts, the program stays light and says so under the Theme box. The text boxes with several lines (the tracker lists) keep a light frame in dark; the drag image of a column header stays light.
- **The Web UI themes were tried in a desktop browser.** A real phone and Safari were not. A third-party theme is a CSS file the operator places in the settings folder; the page's content security policy keeps it from loading anything from elsewhere.
- **The Mac app in dark appearance** was built and run on the test VM; its screen was locked, so the detail tab strip in dark is not confirmed by eye.
- **Do not use it on private trackers yet.** The client ID `RP` is not whitelisted anywhere.

## Reporting problems

Open an [issue](https://github.com/Balls0fSteel/Rookparcel/issues) with your platform, the file you used and what happened. For a crash or a stuck torrent, include the Logger tab or `rookparcel-nox run --verbose` output. On a Mac, Console.app's crash report for Rookparcel helps too. For security problems, see [SECURITY.md](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.29/SECURITY.md).
