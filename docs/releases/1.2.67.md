**Rookparcel 1.2.67** makes the Files tab of the Linux and Mac programs sortable by its columns, as the Windows program's has been since 1.2.65.

Rookparcel is a lean BitTorrent client in the spirit of µTorrent 2.2.1: small single-file binaries, a native look, low RAM and CPU use, and an interface that stays responsive with tens of thousands of torrents. The engine is our own Rust port of libtorrent-rasterbar 2.0.11; nothing is linked.

## New since 1.2.65

- **The Files tab sorts by its columns (Linux and Mac).** Click a header to sort by it, click again to reverse, a third time to go back to the torrent's own order, as on Windows. Names, sizes and piece counts start ascending; Done, % and Priority start with the most first. In the folder view each folder is sorted on its own, folders before files.
  - The sort is remembered, and selected files stay selected as their rows move with progress or a priority change.
  - The Trackers and Peers tabs of the Linux and Mac programs still do not sort.
- **A sorted file list no longer redraws every row for nothing (all three programs).** Sorted by Done or %, each progress update counted as a new order even when no row moved, so the list was reloaded and its selection put back every second. Now that happens only when a row really moves.
- **This release also covers the development version 1.2.66** and fixes what its security review found (the redraw above). The engine, `rookparcel-nox` and the Web UI are as in 1.2.65.

## Updating

- **Windows installer.** Rookparcel 1.2.5 and later offer the update themselves: Help > Check for Updates, then "Download and install". Settings and torrents are kept.
- **macOS.** Quit Rookparcel first, then drag the new `Rookparcel.app` to Applications over the old one.
- **Everything else.** Replace the program, the AppImage or the bundle as before. Settings and torrents are kept.
- **The settings check of 1.2.57** finds nothing to hold for an update from 1.2.65. The Files tab's sort is stored only once you sort.
- **Remote control.** The remote protocol is still 20: 1.2.67, 1.2.65 and 1.2.63 drive each other.
- **Going back to 1.2.65** needs nothing. On Linux and the Mac it ignores the stored sort and shows the files in the torrent's order.
- **From before 1.2.63.** Read [1.2.63's notes](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.67/docs/releases/1.2.63.md#updating) too: the remote protocol changed to 20, and going back below 1.2.63 with Append .!ut ticked needs it unticked first.
- **From before 1.2.45.** The seeding goal changed in 1.2.45: see [its notes](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.67/docs/releases/1.2.45.md#updating).
- **From PaTorrent.** PaTorrent does not offer this update. Install Rookparcel by hand, as in [1.2.5's notes](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.67/docs/releases/1.2.5.md#coming-from-patorrent).

## First run

The website's [install guide](https://balls0fsteel.github.io/Rookparcel/install.html) shows these steps one at a time.

- **Windows installer.** Run the setup. It is not code-signed, so SmartScreen shows "Windows protected your PC": click More info > Run anyway. "Install for anyone using this computer" asks for administrator rights and shows "Unknown publisher". Settings and torrents are in `%APPDATA%\Rookparcel`.
- **Windows zip.** Unzip anywhere and start `rookparcel.exe`; SmartScreen warns as above. An empty `rookparcel.ini` next to the exe keeps settings and torrents beside it (portable mode).
- **macOS.**
  1. Open the disk image and drag `Rookparcel.app` to Applications.
  2. The app is ad-hoc signed and not notarised, so Gatekeeper refuses it the first time. The disk image's `How to open Rookparcel.html` has these steps too.
     - macOS 15 Sequoia and newer: double-click the app and click Done in the warning. Open System Settings > Privacy & Security, scroll to Security and click Open Anyway (offered for about an hour), then confirm with your password or Touch ID.
     - macOS 11 to 14: Control-click (or right-click) the app, choose Open, then click Open.
     - Or, also when macOS says the app "is damaged", run `xattr -dr com.apple.quarantine /Applications/Rookparcel.app` in Terminal.
  3. macOS may ask whether Rookparcel may find devices on local networks. Allow it for peers and a Rookparcel daemon on your own network; downloads from the internet work either way.

  Settings and torrents are in `~/Library/Application Support/Rookparcel/mac`.
- **Linux AppImage.** Run `chmod +x Rookparcel-1.2.67-x86_64.AppImage`, then start it. Without FUSE 2 on the system, start it with `--appimage-extract-and-run`. Settings are in `~/.config/rookparcel/gtk`, torrents in `~/.local/share/rookparcel/gtk`.
- **Linux Flatpak.** The bundle holds the application; the runtime comes from Flathub:

  ```bash
  flatpak remote-add --if-not-exists --user flathub https://dl.flathub.org/repo/flathub.flatpakrepo
  flatpak install --user Rookparcel-1.2.67-x86_64.flatpak
  flatpak run io.github.balls0fsteel.Rookparcel
  ```

- **Headless.** `rookparcel-nox run --webui 8080 --webui-pass PASS` starts the daemon with its Web UI and a qBittorrent-compatible Web API on port 8080. [DAEMON.md](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.67/docs/DAEMON.md) describes services: systemd, FreeBSD rc.d, `--daemon` and Windows, one per profile if you like. Your own Web UI themes go in `webui/themes` under its settings folder (`/config` in Docker).
- **Docker.**

  ```bash
  docker run -d --name rookparcel -p 8080:8080 -p 6881:6881 -p 6881:6881/udp -e ROOKPARCEL_WEBUI_PASS=choose-one -v rookparcel-config:/config -v /srv/media:/downloads ghcr.io/balls0fsteel/rookparcel-nox:1.2.67
  ```

  Then open `http://<host>:8080` and log in as `admin`. Without `ROOKPARCEL_WEBUI_PASS`, `docker logs rookparcel` shows a temporary password. Stop it with `docker stop -t 60 rookparcel`, so it has time to save its torrents.

## Known limitations

- **What was tried.** Unit tests on Windows, Linux, macOS and FreeBSD. The Linux program was tried under a virtual X server on Xubuntu, and the Mac program on an Intel macOS VM: all three clicks, the sort kept across a restart, the selection following a priority change. Rows moved by a running download while sorted by Done or % were not seen on either. The release files were not started on a desktop before publishing.
- **Linux: the keyboard cursor** stays at its row position when rows move by themselves; the selection follows the files.
- **A torrent with tens of thousands of files** sorted by Done or % is sorted again at each progress update, and on Linux and the Mac the whole list is redrawn whenever a row moves.
- Everything in [1.2.65's limitations](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.67/docs/releases/1.2.65.md#known-limitations) but the Files tab's sort, [1.2.63's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.67/docs/releases/1.2.63.md#known-limitations), [1.2.0's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.67/docs/releases/1.2.0.md#known-limitations), [1.2.5's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.67/docs/releases/1.2.5.md#known-limitations), [1.2.19's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.67/docs/releases/1.2.19.md#known-limitations), [1.2.21's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.67/docs/releases/1.2.21.md#known-limitations), [1.2.30's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.67/docs/releases/1.2.30.md#known-limitations), [1.2.44's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.67/docs/releases/1.2.44.md#known-limitations), [1.2.45's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.67/docs/releases/1.2.45.md#known-limitations), [1.2.46's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.67/docs/releases/1.2.46.md#known-limitations), [1.2.54's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.67/docs/releases/1.2.54.md#known-limitations), [1.2.57's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.67/docs/releases/1.2.57.md#known-limitations) still applies.
- **Do not use it on private trackers yet.** The client ID `RP` is not whitelisted anywhere.

## Reporting problems

Open an [issue](https://github.com/Balls0fSteel/Rookparcel/issues) with your platform, the file you used and what happened. For a crash or a stuck torrent, include the Logger tab or `rookparcel-nox run --verbose` output. On a Mac, Console.app's crash report for Rookparcel helps too. For security problems, see [SECURITY.md](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.67/SECURITY.md).
