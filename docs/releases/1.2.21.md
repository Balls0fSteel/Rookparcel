**Rookparcel 1.2.21** shows a torrent's files in their folders. The Files tab now has the same tree as the Add Torrent dialog in every app (Windows, Linux, macOS and the Web UI), and one click gives back µTorrent's single list of paths. The Add Torrent dialog gets a file filter and type-ahead, the GTK app no longer closes on some systems as soon as a torrent is listed, and `rookparcel-nox` now comes as a Docker image too.

Rookparcel is a lean BitTorrent client in the spirit of µTorrent 2.2.1: small single-file binaries, a native look, low RAM and CPU use, and an interface that stays responsive with tens of thousands of torrents. The engine is our own Rust port of libtorrent-rasterbar 2.0.11; nothing is linked.

## New since 1.2.19

Version 1.2.20 was a development step and was never released; this list covers it.

- **The Files tab's folder tree.** The torrent's files show in their folders, as in the Add Torrent dialog:
  - folders open and close with their arrow, a double click, or the Left and Right keys; Left on a file goes to its folder;
  - a folder adds up its files' Size and Done, and shows their priority, or Mixed when they differ;
  - a priority, Don't Download or Prioritize by File Order chosen on a folder applies to all its files (only the shown ones while the filter is on); Open on a folder opens the folder;
  - folders you close stay closed while the torrent downloads and after priority changes.
- **Tree view or one list.** The **Tree view** button beside the Filter files box, or **Tree View** in the tab's right-click menu, switches to µTorrent 2.2.1's single list of paths. Rookparcel remembers the choice (the Web UI per browser).
- **Add Torrent: filter and type-ahead.** A Filter files box above the dialog's files shows only those whose path has every word you type, so you can check or uncheck them in one go; Select All, Select None and a folder's check box then act on the shown files only. Typing a letter jumps to the next file starting with it, in all four apps.
- **Windows: type-ahead in the lists.** Typing in the torrent list, the Files tab and the other detail tabs jumps to the matching row, as in Explorer.
- **Web UI:** the Add dialog and the Files tab are driven by the keyboard too (arrows, Space, letters).
- **Docker.** `ghcr.io/balls0fsteel/rookparcel-nox:1.2.21` (and `:latest`) runs the daemon with its Web UI and qBittorrent-compatible API on amd64 and arm64. Settings and torrents live in the `/config` volume, downloads in `/downloads`; `ROOKPARCEL_WEBUI_PASS` sets the login. The [Docker page](https://github.com/Balls0fSteel/Rookparcel/wiki/Docker) has a Compose file for use with Sonarr, Radarr and Prowlarr.
- **Fix (GTK):** since 1.2.0, the GTK app could close at once (or show an empty list) as soon as a torrent was in the list; it was seen with GTK 4.22. The alternate-row shading changed rows GTK was still building.

## Updating

- **Windows installer.** Rookparcel 1.2.5 and later offer the update themselves: Help > Check for Updates, then "Download and install". Settings and torrents are kept.
- **macOS.** Quit Rookparcel first, then drag the new `Rookparcel.app` to Applications over the old one.
- **Everything else.** Replace the program, the AppImage or the bundle as before. Settings and torrents are kept.
- **Remote control.** The remote protocol is unchanged (16), so 1.2.5 to 1.2.21 GUIs and daemons work with each other.
- **From PaTorrent.** PaTorrent does not offer this update. Install Rookparcel by hand, as in [1.2.5's notes](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.21/docs/releases/1.2.5.md#coming-from-patorrent).

## First run

- **Windows installer.** Run the setup. It is not code-signed, so SmartScreen shows "Windows protected your PC": click More info > Run anyway. "Install for anyone using this computer" asks for administrator rights and shows "Unknown publisher". Settings and torrents are in `%APPDATA%\Rookparcel`.
- **Windows zip.** Unzip anywhere and start `rookparcel.exe`; SmartScreen warns as above. An empty `rookparcel.ini` next to the exe keeps settings and torrents beside it (portable mode).
- **macOS.**
  1. Open the disk image and drag `Rookparcel.app` to Applications.
  2. The app is ad-hoc signed and not notarised, so Gatekeeper refuses it the first time. Right-click (or Control-click) the app, choose Open, then click Open. If macOS offers no Open button, open System Settings > Privacy & Security and click Open Anyway. Or run `xattr -dr com.apple.quarantine /Applications/Rookparcel.app` in Terminal.
  3. macOS may ask whether Rookparcel may find devices on local networks. Allow it for peers and a Rookparcel daemon on your own network; downloads from the internet work either way.

  Settings and torrents are in `~/Library/Application Support/Rookparcel/mac`.
- **Linux AppImage.** Run `chmod +x Rookparcel-1.2.21-x86_64.AppImage`, then start it. Without FUSE 2 on the system, start it with `--appimage-extract-and-run`. Settings are in `~/.config/rookparcel/gtk`, torrents in `~/.local/share/rookparcel/gtk`.
- **Linux Flatpak.** The bundle holds the application; the runtime comes from Flathub:

  ```bash
  flatpak remote-add --if-not-exists --user flathub https://dl.flathub.org/repo/flathub.flatpakrepo
  flatpak install --user Rookparcel-1.2.21-x86_64.flatpak
  flatpak run io.github.balls0fsteel.Rookparcel
  ```

- **Headless.** `rookparcel-nox run --webui 8080 --webui-pass PASS` starts the daemon with its Web UI and a qBittorrent-compatible Web API on port 8080. [DAEMON.md](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.21/docs/DAEMON.md) describes services: systemd, FreeBSD rc.d, `--daemon` and Windows, one per profile if you like.
- **Docker.**

  ```bash
  docker run -d --name rookparcel -p 8080:8080 -p 6881:6881 -p 6881:6881/udp -e ROOKPARCEL_WEBUI_PASS=choose-one -v rookparcel-config:/config -v /srv/media:/downloads ghcr.io/balls0fsteel/rookparcel-nox:1.2.21
  ```

  Then open `http://<host>:8080` and log in as `admin`. Without `ROOKPARCEL_WEBUI_PASS`, `docker logs rookparcel` shows a temporary password. Stop it with `docker stop -t 60 rookparcel`, so it has time to save its torrents.

## Known limitations

- Everything in [1.2.0's limitations](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.21/docs/releases/1.2.0.md#known-limitations), [1.2.5's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.21/docs/releases/1.2.5.md#known-limitations) and [1.2.19's](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.21/docs/releases/1.2.19.md#known-limitations) still applies.
- **The folder tree was tried by hand in a test machine for each app**, not with right-to-left languages, at high DPI on Windows, or on a real phone. In the Mac app, Return does not open a file while the tree is shown (a double click does).
- **The Docker image was tried on amd64 only.** UPnP and NAT-PMP do not reach the router from Docker's default network: forward port 6881 yourself, or run the container with `--network host`. Other containers reaching the Web UI by name (`http://rookparcel:8080`) need that name under Preferences > Web UI > Server domains.
- **Do not use it on private trackers yet.** The client ID `RP` is not whitelisted anywhere.

## Reporting problems

Open an [issue](https://github.com/Balls0fSteel/Rookparcel/issues) with your platform, the file you used and what happened. For a crash or a stuck torrent, include the Logger tab or `rookparcel-nox run --verbose` output. On a Mac, Console.app's crash report for Rookparcel helps too. For security problems, see [SECURITY.md](https://github.com/Balls0fSteel/Rookparcel/blob/v1.2.21/SECURITY.md).
