Install Rookparcel

From the downloaded file to the running program, step by step. The files are on the Download page.

Windows and macOS warn the first time. Rookparcel's files are not code-signed and the Mac app is not notarised by Apple, so the system cannot tell who made them. The steps below show what the warning looks like and what to click. To check that a file is the published one, compare its checksum.

Windows

Windows 10 or 11, 64-bit. The installer adds a Start menu entry and updates in place; the zip installs nothing.

The installer

  1. 1 Download the setup and run it

    Take rookparcel-…-windows-x64-setup.exe from the Download page and open it from your browser's downloads or the Downloads folder.

  2. 2 SmartScreen: More info

    Windows shows “Windows protected your PC”. Click the small More info link under the text. If no such window appears, go on to the next step.

    Windows protected your PC

    Microsoft Defender SmartScreen prevented an unrecognised app from starting. More info

    Don't run

  3. 3 SmartScreen: Run anyway

    The window now names the file and says “Unknown publisher”. Click Run anyway.

    Windows protected your PC

    App: rookparcel-…-setup.exe
    Publisher: Unknown publisher

    Run anywayDon't run

  4. 4 Choose who it is for

    Pick the language and accept the licence. On Choose Users, Install just for me needs no administrator rights. Install for anyone using this computer makes Windows ask for permission; that prompt also says “Unknown publisher”. Click Yes.

    User Account Control
    Do you want to allow this app from an unknown publisher to make changes to your device?

    rookparcel-…-setup.exe
    Publisher: Unknown

    YesNo

  5. 5 Components, folder, Install

    Leave the ticks as they are unless you do not want the desktop shortcut or the .torrent and magnet: associations. Keep the folder shown and click Install.

  6. 6 Finish

    Leave Run Rookparcel ticked and click Finish. Rookparcel opens with its Setup Guide. Later versions install over this one: Rookparcel tells you in its status bar when one is out.

The portable zip

  1. 1 Download and unzip

    Take rookparcel-…-windows-x64.zip from the Download page. Right-click it, choose Extract All… and pick a folder you can write to, such as Documents\Rookparcel. Do not start it from inside the zip.

  2. 2 Optional: keep everything in that folder

    For portable mode, make an empty file named rookparcel.ini next to rookparcel.exe before the first start. Settings and torrents then stay in the folder; without it they go to %APPDATA%\Rookparcel.

  3. 3 Start rookparcel.exe

    Double-click rookparcel.exe. Windows shows “Windows protected your PC” the first time: click More info, then Run anyway.

    Windows protected your PC

    App: rookparcel.exe
    Publisher: Unknown publisher

    Run anywayDon't run

  4. 4 Optional: open torrents with it

    Tick the .torrent and magnet: associations in Options > Preferences > General. They name this copy, so they stop working if you move the folder.

Linux

x86_64 (Intel and AMD) or aarch64 (64-bit ARM); uname -m tells which. The commands below work in the folder that holds the download, usually ~/Downloads.

AppImage

  1. 1 Download the AppImage

    Take Rookparcel-…-x86_64.AppImage (or -aarch64) from the Download page. It needs glibc 2.39 or newer: Ubuntu 24.04, Fedora 40, Debian 13 or later.

  2. 2 Allow it to run

    A downloaded file may not be run until you say so. In a terminal:

    cd ~/Downloads
chmod +x Rookparcel-*.AppImage

    Or in the file manager: right-click the file, Properties, Permissions, and tick the box that allows running it as a program.

  3. 3 Start it

    Double-click the file, or:

    ./Rookparcel-*.AppImage

  4. 4 If it says it needs FUSE

    Some systems no longer ship FUSE 2, and the AppImage then stops with “AppImages require FUSE to run”. Start it this way instead:

    ./Rookparcel-*.AppImage --appimage-extract-and-run

Flatpak

  1. 1 Download the bundle

    Take Rookparcel-…-x86_64.flatpak (or -aarch64) from the Download page. Your system needs flatpak itself; most desktops have it.

  2. 2 Add Flathub once

    The bundle holds the application; its runtime comes from Flathub:

    flatpak remote-add --if-not-exists --user flathub https://dl.flathub.org/repo/flathub.flatpakrepo

  3. 3 Install the bundle

    cd ~/Downloads
flatpak install --user Rookparcel-*.flatpak

    Answer y when it asks about the runtime.

  4. 4 Start it

    Rookparcel is now in your applications menu, or:

    flatpak run io.github.balls0fsteel.Rookparcel

    It may write to your home folder. For downloads on another disk, see Good to know on the Download page.

Plain binaries

  1. 1 Download the archive

    Take rookparcel-…-linux-x86_64.tar.gz (or -aarch64) from the Download page. The programs use your system's GTK 4 (4.12 or newer) and OpenSSL 3, as Ubuntu 24.04 has them.

  2. 2 Unpack it

    cd ~/Downloads
tar -xzf rookparcel-*-linux-*.tar.gz

  3. 3 Start the window

    ./rookparcel-*-linux-*/rookparcel-gtk

    The folder also holds rookparcel-nox (the daemon), a desktop entry and systemd units.

macOS

macOS 11 Big Sur or newer, Apple silicon and Intel. Apple menu > About This Mac shows your macOS version. The disk image carries these steps too, in How to open Rookparcel.html.

macOS 15 Sequoia or newer

  1. 1 Copy the app to Applications

    Open Rookparcel-…-macos.dmg from the Download page and drag Rookparcel.app onto the Applications folder in its window. Start it from Applications, not from the disk image.

  2. 2 Try to open it, then click Done

    Double-click Rookparcel in Applications. macOS says it could not verify the app. Click Done, not Move to Trash.

    “Rookparcel” Not Opened

    Apple could not verify “Rookparcel” is free of malware that may harm your Mac or compromise your privacy.

    Move to TrashDone

  3. 3 System Settings: Open Anyway

    Open System Settings from the Apple menu and click Privacy & Security in the sidebar. Scroll down to Security and click Open Anyway next to the line about Rookparcel. The button is there for about an hour after step 2; if it is gone, repeat step 2.

    Privacy & Security
    Security

    “Rookparcel” was blocked to protect your Mac.

    Open Anyway

  4. 4 Confirm

    In the question that follows, click Open Anyway, then give your password or Touch ID. Rookparcel starts, and from now on opens with a double-click.

    Open “Rookparcel”?

    Apple is not able to verify that it is free from malware.

    Open AnywayMove to TrashDone

  5. 5 Local network

    macOS may ask whether Rookparcel may find devices on your local network. Allow it for local peer discovery and for opening a port on your router; Rookparcel also works without.

    Allow “Rookparcel” to find devices on local networks?
    Don't AllowAllow

macOS 11 to 14

  1. 1 Copy the app to Applications

    Open Rookparcel-…-macos.dmg from the Download page and drag Rookparcel.app onto the Applications folder in its window.

  2. 2 Control-click, then Open

    A double-click only shows a warning with no way on. Instead, in Applications, hold Control and click Rookparcel (or right-click it) and choose Open from the menu.

  3. 3 Open

    This time the warning has an Open button. Click it. Rookparcel starts, and from now on opens with a double-click.

    macOS cannot verify the developer of “Rookparcel”. Are you sure you want to open it?
    Move to TrashOpenCancel

  4. 4 If there is no Open button

    Open System Settings (System Preferences on macOS 11 and 12) > Privacy & Security and click Open Anyway, or use the Terminal.

With the Terminal, or when macOS says “is damaged”

  1. 1 Copy the app to Applications

    Open Rookparcel-…-macos.dmg and drag Rookparcel.app onto the Applications folder in its window.

  2. 2 Remove the download mark

    Open Terminal (Applications > Utilities), paste this line and press Return:

    xattr -dr com.apple.quarantine /Applications/Rookparcel.app

    It removes the “downloaded from the internet” mark from this one app. It prints nothing when it worked.

  3. 3 Open it

    Double-click Rookparcel in Applications. It starts without a warning. “Rookparcel is damaged and can't be opened” is the same block in other words; this command clears it too.
