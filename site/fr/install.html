Installer Rookparcel

Du fichier téléchargé au programme en marche, pas à pas. Les fichiers se trouvent sur la page Télécharger.

Windows et macOS avertissent au premier lancement. Les fichiers de Rookparcel ne sont pas signés et l'application pour Mac n'est pas notarisée par Apple : le système ne peut donc pas savoir qui les a créés. Les étapes ci-dessous montrent à quoi ressemble l'avertissement et sur quoi cliquer. Pour vérifier qu'un fichier est bien celui qui a été publié, comparez sa somme de contrôle.

Windows

Windows 10 ou 11, 64 bits. L'installateur ajoute une entrée dans le menu Démarrer et se met à jour sur place ; le zip n'installe rien.

L'installateur

  1. 1 Télécharger l'installateur et le lancer

    Prenez rookparcel-…-windows-x64-setup.exe sur la page Télécharger et ouvrez-le depuis les téléchargements de votre navigateur ou depuis le dossier Téléchargements.

  2. 2 SmartScreen : Informations complémentaires

    Windows affiche « Windows a protégé votre ordinateur ». Cliquez sur le petit lien Informations complémentaires sous le texte. Si cette fenêtre n'apparaît pas, passez à l'étape suivante.

    Windows a protégé votre ordinateur

    Microsoft Defender SmartScreen a empêché le démarrage d'une application non reconnue. Informations complémentaires

    Ne pas exécuter

  3. 3 SmartScreen : Exécuter quand même

    La fenêtre indique maintenant le nom du fichier et « Éditeur inconnu ». Cliquez sur Exécuter quand même.

    Windows a protégé votre ordinateur

    Application : rookparcel-…-setup.exe
    Éditeur : Éditeur inconnu

    Exécuter quand mêmeNe pas exécuter

  4. 4 Choisir pour qui l'installer

    Choisissez la langue et acceptez la licence. Sur Choix des utilisateurs, Installer seulement pour moi ne demande pas de droits d'administrateur. Installer pour tous les utilisateurs de cet ordinateur fait demander l'autorisation à Windows ; cette demande indique aussi « Éditeur inconnu ». Cliquez sur Oui.

    Contrôle de compte d'utilisateur
    Voulez-vous autoriser cette application d'un éditeur inconnu à apporter des modifications à votre appareil ?

    rookparcel-…-setup.exe
    Éditeur : Inconnu

    OuiNon

  5. 5 Composants, dossier, Installer

    Laissez les cases cochées, sauf si vous ne voulez pas du raccourci sur le Bureau ni des associations avec les fichiers .torrent et les liens magnet:. Gardez le dossier proposé et cliquez sur Installer.

  6. 6 Terminer

    Laissez Exécuter Rookparcel coché et cliquez sur Terminer. Rookparcel s'ouvre avec son Assistant de configuration. Les versions suivantes s'installent par-dessus celle-ci : Rookparcel l'indique dans sa barre d'état quand une nouvelle version est disponible.

Le zip portable

  1. 1 Télécharger et décompresser

    Prenez rookparcel-…-windows-x64.zip sur la page Télécharger. Faites un clic droit dessus, choisissez Extraire tout… et indiquez un dossier où vous pouvez écrire, par exemple Documents\Rookparcel. Ne le lancez pas depuis l'intérieur du zip.

  2. 2 Facultatif : tout garder dans ce dossier

    Pour le mode portable, créez un fichier vide nommé rookparcel.ini à côté de rookparcel.exe avant le premier lancement. Les réglages et les torrents restent alors dans le dossier ; sans ce fichier, ils vont dans %APPDATA%\Rookparcel.

  3. 3 Lancer rookparcel.exe

    Double-cliquez sur rookparcel.exe. Windows affiche « Windows a protégé votre ordinateur » la première fois : cliquez sur Informations complémentaires, puis sur Exécuter quand même.

    Windows a protégé votre ordinateur

    Application : rookparcel.exe
    Éditeur : Éditeur inconnu

    Exécuter quand mêmeNe pas exécuter

  4. 4 Facultatif : ouvrir les torrents avec Rookparcel

    Cochez les associations .torrent et magnet: dans Options > Préférences > Général. Elles désignent cette copie : elles cessent de fonctionner si vous déplacez le dossier.

Linux

x86_64 (Intel et AMD) ou aarch64 (ARM 64 bits) ; uname -m indique lequel. Les commandes ci-dessous s'exécutent dans le dossier qui contient le fichier téléchargé, en général ~/Downloads.

AppImage

  1. 1 Télécharger l'AppImage

    Prenez Rookparcel-…-x86_64.AppImage (ou -aarch64) sur la page Télécharger. Elle demande glibc 2.34 ou plus récent : Ubuntu 22.04, Debian 12, Fedora 35, RHEL 9 ou une version ultérieure.

  2. 2 Autoriser son exécution

    Un fichier téléchargé ne peut pas être exécuté tant que vous ne l'avez pas permis. Dans un terminal :

    cd ~/Downloads
chmod +x Rookparcel-*.AppImage

    Ou dans le gestionnaire de fichiers : faites un clic droit sur le fichier, choisissez Propriétés, puis Permissions, et cochez la case qui permet de l'exécuter comme un programme.

  3. 3 Le lancer

    Double-cliquez sur le fichier, ou :

    ./Rookparcel-*.AppImage

  4. 4 S'il indique avoir besoin de FUSE

    Certains systèmes ne fournissent plus FUSE 2, et l'AppImage s'arrête alors avec « AppImages require FUSE to run ». Lancez-la plutôt ainsi :

    ./Rookparcel-*.AppImage --appimage-extract-and-run

Flatpak

  1. 1 Télécharger le paquet

    Prenez Rookparcel-…-x86_64.flatpak (ou -aarch64) sur la page Télécharger. Votre système a besoin de flatpak lui-même ; la plupart des bureaux l'ont.

  2. 2 Ajouter Flathub, une seule fois

    Le paquet contient l'application ; son environnement d'exécution vient de Flathub :

    flatpak remote-add --if-not-exists --user flathub https://dl.flathub.org/repo/flathub.flatpakrepo

  3. 3 Installer le paquet

    cd ~/Downloads
flatpak install --user Rookparcel-*.flatpak

    Répondez y quand il pose la question sur l'environnement d'exécution.

  4. 4 Le lancer

    Rookparcel figure maintenant dans le menu des applications, ou :

    flatpak run io.github.balls0fsteel.Rookparcel

    Il peut écrire dans votre dossier personnel. Pour télécharger sur un autre disque, voir À savoir sur la page Télécharger.

Binaires seuls

  1. 1 Télécharger l'archive

    Prenez rookparcel-…-linux-x86_64.tar.gz (ou -aarch64) sur la page Télécharger. Les programmes utilisent le GTK 4 (4.12 ou plus récent) et l'OpenSSL 3 de votre système, tels qu'Ubuntu 24.04 les fournit.

  2. 2 La décompresser

    cd ~/Downloads
tar -xzf rookparcel-*-linux-*.tar.gz

  3. 3 Lancer la fenêtre

    ./rookparcel-*-linux-*/rookparcel-gtk

    Le dossier contient aussi rookparcel-nox (le démon), une entrée de bureau et des unités systemd.

macOS

macOS 11 Big Sur ou plus récent, Apple silicon et Intel. Menu Pomme > À propos de ce Mac indique votre version de macOS. L'image disque contient aussi ces étapes, dans How to open Rookparcel.html.

macOS 15 Sequoia ou plus récent

  1. 1 Copier l'application dans Applications

    Ouvrez Rookparcel-…-macos.dmg depuis la page Télécharger et faites glisser Rookparcel.app sur le dossier Applications dans sa fenêtre. Lancez-la depuis Applications, pas depuis l'image disque.

  2. 2 Essayer de l'ouvrir, puis cliquer sur OK

    Double-cliquez sur Rookparcel dans Applications. macOS indique qu'il n'a pas pu vérifier l'application. Cliquez sur OK, pas sur Placer dans la corbeille.

    « Rookparcel » n'a pas été ouvert

    Apple n'a pas pu vérifier que « Rookparcel » ne contient pas de logiciel malveillant susceptible de porter atteinte à votre Mac ou de compromettre votre confidentialité.

    Placer dans la corbeilleOK

  3. 3 Réglages Système : Ouvrir quand même

    Ouvrez Réglages Système depuis le menu Pomme et cliquez sur Confidentialité et sécurité dans la barre latérale. Faites défiler jusqu'à Sécurité et cliquez sur Ouvrir quand même à côté de la ligne qui parle de Rookparcel. Le bouton reste là environ une heure après l'étape 2 ; s'il a disparu, recommencez l'étape 2.

    Confidentialité et sécurité
    Sécurité

    « Rookparcel » a été bloqué afin de protéger votre Mac.

    Ouvrir quand même

  4. 4 Confirmer

    Dans la question qui suit, cliquez sur Ouvrir quand même, puis donnez votre mot de passe ou utilisez Touch ID. Rookparcel démarre et, désormais, s'ouvre par un double-clic.

    Ouvrir « Rookparcel » ?

    Apple ne peut pas vérifier qu'il ne contient pas de logiciel malveillant.

    Ouvrir quand mêmePlacer dans la corbeilleOK

  5. 5 Réseau local

    macOS peut demander si Rookparcel a le droit de trouver des appareils sur votre réseau local. Choisissez Autoriser pour la découverte de pairs locaux et pour l'ouverture d'un port sur votre routeur ; Rookparcel fonctionne aussi sans cela.

    Autoriser « Rookparcel » à trouver des appareils sur les réseaux locaux ?

macOS 11 à 14

  1. 1 Copier l'application dans Applications

    Ouvrez Rookparcel-…-macos.dmg depuis la page Télécharger et faites glisser Rookparcel.app sur le dossier Applications dans sa fenêtre.

  2. 2 Contrôle-clic, puis Ouvrir

    Un double-clic n'affiche qu'un avertissement sans issue. Dans Applications, maintenez plutôt la touche Contrôle et cliquez sur Rookparcel (ou faites un clic droit dessus), puis choisissez Ouvrir dans le menu.

  3. 3 Ouvrir

    Cette fois, l'avertissement comporte un bouton Ouvrir. Cliquez dessus. Rookparcel démarre et, désormais, s'ouvre par un double-clic.

    macOS ne peut pas vérifier le développeur de « Rookparcel ». Voulez-vous vraiment l'ouvrir ?
    Placer dans la corbeilleOuvrirAnnuler

  4. 4 S'il n'y a pas de bouton Ouvrir

    Ouvrez Réglages Système (Préférences Système sous macOS 11 et 12) > Confidentialité et sécurité et cliquez sur Ouvrir quand même, ou utilisez le Terminal.

Avec le Terminal, ou quand macOS dit « est endommagé »

  1. 1 Copier l'application dans Applications

    Ouvrez Rookparcel-…-macos.dmg et faites glisser Rookparcel.app sur le dossier Applications dans sa fenêtre.

  2. 2 Retirer la marque de téléchargement

    Ouvrez Terminal (Applications > Utilitaires), collez cette ligne et appuyez sur Retour :

    xattr -dr com.apple.quarantine /Applications/Rookparcel.app

    Elle retire la marque « téléchargé depuis Internet » de cette seule application. Elle n'affiche rien quand elle a réussi.

  3. 3 L'ouvrir

    Double-cliquez sur Rookparcel dans Applications. Elle démarre sans avertissement. « Rookparcel est endommagé et ne peut pas être ouvert » est le même blocage dit autrement ; cette commande le lève aussi.
