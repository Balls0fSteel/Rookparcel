Télécharger Rookparcel

Toutes les versions se trouvent sur la page des versions sur GitHub.

Ceci est une préversion. Elle a été peu testée en dehors des machines de son auteur, les réglages peuvent encore changer avant la 1.0, et il ne faut pas encore l'utiliser sur des trackers privés. Ses notes de version listent les limites connues.

Guide d'installation pas à pas : du téléchargement au programme en marche, avec les avertissements du système au premier lancement.

Quel fichier me faut-il ?

  • Windows 10 ou 11 L'installeur met Rookparcel en place et le met ensuite à jour sur place (à partir de la 1.0.1). Le zip portable n'installe rien : décompressez-le et lancez.
  • Bureau Linux L'AppImage embarque ses bibliothèques et demande glibc 2.39 ou plus récent (Ubuntu 24.04, Fedora 40, Debian 13 ou plus récent). Vous préférez Flatpak ? Prenez le bundle. Les binaires seuls utilisent le GTK 4 et l'OpenSSL 3 de votre système.
  • Serveur Linux L'AppImage rookparcel-nox, ou rookparcel-nox tiré des binaires seuls, avec son interface web.
  • Mac L'image disque, pour les Mac Apple silicon comme Intel. Les serveurs peuvent utiliser rookparcel-nox, sans interface.

x64 et x86_64 désignent les processeurs Intel et AMD ; aarch64 et arm64 désignent l'ARM 64 bits.

Windows Votre système

Windows 10 ou 11, 64 bits (x64).

La liste des fichiers est remplie à la construction du site. Tous les fichiers se trouvent sur la page des versions sur GitHub.

SmartScreen

Les programmes ne sont pas signés ; la première fois, Windows SmartScreen affiche « Windows a protégé votre ordinateur ». Choisissez Informations complémentaires, puis Exécuter quand même. Le guide d'installation montre chaque étape.

Les réglages et les torrents vont dans %APPDATA%\Rookparcel. Un fichier rookparcel.ini vide à côté de rookparcel.exe les garde plutôt dans ce dossier, avec les téléchargements dans son sous-dossier Downloads (mode portable, détails). --profile work ou Fichier > Profils lance un Rookparcel séparé à côté de l'habituel.

Linux Votre système

x86_64 ou aarch64.

La liste des fichiers est remplie à la construction du site. Tous les fichiers se trouvent sur la page des versions sur GitHub.

Bon à savoir

  • Les réglages sont dans ~/.config/rookparcel/gtk, les torrents dans ~/.local/share/rookparcel/gtk. Le Flatpak les garde sous ~/.var/app/io.github.balls0fsteel.Rookparcel/. Un fichier rookparcel.ini vide à côté de rookparcel-gtk ou du fichier .AppImage garde tout dans ce dossier à la place (mode portable, pas dans le Flatpak).
  • Le Flatpak peut écrire dans votre dossier personnel, car un client torrent écrit en continu dans les dossiers que vous choisissez. Un dossier sur un autre disque demande flatpak override --user --filesystem=/mnt/data io.github.balls0fsteel.Rookparcel (avec votre dossier).
  • Le démon comme service systemd : docs/DAEMON.md.

macOS Votre système

L'interface : Apple silicon et Intel, macOS 11 Big Sur ou plus récent. Le démon : Apple silicon (macOS 11 ou plus récent) et Intel (macOS 10.14 ou plus récent).

La liste des fichiers est remplie à la construction du site. Tous les fichiers se trouvent sur la page des versions sur GitHub.

Gatekeeper

Rookparcel.app est signée ad hoc et non notariée ; Gatekeeper la refuse donc la première fois (« Non ouvert », ou « ne peut pas être ouvert car le développeur ne peut pas être vérifié »). Autorisez-la une fois ; le guide d'installation montre chaque étape, et l'image disque les contient dans How to open Rookparcel.html.

  • macOS 15 Sequoia et plus récent : essayez d'ouvrir l'application et cliquez sur Terminé. Ouvrez ensuite Réglages Système > Confidentialité et sécurité, cliquez sur Ouvrir quand même sous Sécurité, et confirmez.
  • macOS 11 à 14 : faites un clic en maintenant la touche Contrôle (ou un clic droit) sur l'application, choisissez Ouvrir, puis Ouvrir de nouveau.

Ou, aussi quand macOS dit que l'application « est endommagée », retirez l'indicateur de quarantaine après l'avoir copiée dans Applications :

xattr -dr com.apple.quarantine /Applications/Rookparcel.app

Rookparcel.app est un programme macOS natif, un seul fichier pour Apple silicon et Intel. Les réglages et les torrents sont dans ~/Library/Application Support/Rookparcel/mac. Si vous venez de l'ancienne version GTK de l'application, son dossier gtk à cet endroit devient mac au premier démarrage, de sorte que les réglages et les torrents sont repris.

Sans interface : rookparcel-nox

Le démon se trouve dans le zip Windows, dans les binaires seuls pour Linux, dans sa propre AppImage Linux et dans l'archive tar macOS. Lancez-le avec l'interface web sur le port 8080 :

rookparcel-nox run --webui 8080 --webui-pass PASS

Ouvrez ensuite http://127.0.0.1:8080 sur la même machine et connectez-vous en tant que admin. Sans --webui-pass, il affiche un mot de passe temporaire au premier démarrage ; définissez-en un dans Préférences > Interface web. Le même port sert une API web compatible avec qBittorrent pour les outils existants.

Depuis d'autres machines : donnez une adresse, comme --webui 0.0.0.0:8443, et ajoutez --webui-https pour que le mot de passe ne circule pas en clair (un certificat auto-signé est créé à la première utilisation). rookparcel-nox add file.torrent --save DIR ajoute un torrent. Son exécution comme service (systemd, rc.d de FreeBSD, service Windows, --daemon) est décrite dans docs/DAEMON.md.

Vérifier un téléchargement

Chaque version de la page des versions a un fichier SHA256SUMS.

Avec SHA256SUMS dans le même dossier que votre téléchargement :

Linux

sha256sum -c --ignore-missing SHA256SUMS

macOS

shasum -a 256 Rookparcel-*.dmg

Comparez le résultat avec la ligne du fichier dans SHA256SUMS.

Windows (PowerShell)

Get-FileHash .\rookparcel-*.zip

Comparez l'empreinte avec la ligne du fichier dans SHA256SUMS (la casse n'a pas d'importance).

Mise à jour

Rookparcel ne se met pas à jour tout seul. À partir de la 1.0.1, les interfaces affichent une courte note dans leur barre d'état quand une version plus récente est disponible (à partir de la 1.1.17, rookparcel-nox affiche une ligne et montre un lien dans son interface web) ; téléchargez-la depuis cette page ou depuis GitHub. Ce qui a changé est sur la page Actualités. La vérification lit un petit fichier de ce site et peut être désactivée (ce qu'elle envoie).

  • Installeur : lancez le nouvel installeur. Il met à jour la copie installée sur place.
  • Zip portable : quittez Rookparcel, puis remplacez à la main rookparcel.exe et rookparcel-nox.exe par les nouveaux. Vos réglages restent où ils sont (en mode portable, laissez le reste de ce dossier tel quel).
  • AppImage : remplacez l'ancien fichier par le nouveau.
  • Flatpak : installez le nouveau bundle par-dessus l'ancien avec flatpak install --user --reinstall suivi de son nom de fichier.
  • Binaires seuls et archive tar macOS : décompressez la nouvelle archive et utilisez ses programmes.
  • macOS : faites glisser la nouvelle Rookparcel.app dans Applications et remplacez l'ancienne.

Les versions plus anciennes et toutes les préversions sont sur la page des versions. Pour compiler Rookparcel vous-même, voyez Building dans le README.
