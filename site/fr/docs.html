Documentation

Les documents de Rookparcel sont pour l'instant dans son dépôt GitHub. Cette page y renvoie.

Le guide de l'utilisateur est le wiki de Rookparcel. Une trentaine de pages sur l'installation, l'ajout et la gestion des torrents, chaque réglage, l'interface web, le démon sans interface, Docker, Sonarr et Radarr, et le dépannage, avec des captures d'écran. Il existe aussi en Français, Español, Deutsch et Magyar.

Ligne de commande

Les options courantes. rookparcel-nox --help les liste toutes.

Options de la ligne de commande
CommandeCe qu'elle fait
rookparcel-nox runLance le démon et reprend chaque torrent enregistré ; q puis Entrée, ou Ctrl+C, l'arrêtent proprement.
rookparcel-nox run --webui 8080 --webui-pass PASSPareil, avec l'interface web et l'API web compatible avec qBittorrent sur 127.0.0.1:8080 (--webui ADDR:PORT pour une autre adresse).
--webui-httpsSert l'interface web en HTTPS avec un certificat auto-signé créé à la première utilisation ; --webui-cert FILE --webui-key FILE utilise le vôtre.
rookparcel-nox add file.torrent --save DIRTélécharge un torrent dans DIR et s'arrête quand c'est fini (--seed continue à le partager jusqu'à l'arrêt).
--no-update-checkLance le démon sans sa vérification d'une version plus récente (1.1.17 et suivantes ; Préférences > Général > Confidentialité dans l'interface web fait la même chose).
rookparcel-nox run --verboseAffiche les événements des trackers et des pairs, utile dans un rapport de bogue.
rookparcel-nox --licenseAffiche la licence et les avis des composants tiers.
rookparcel --remote, rookparcel-gtk --remoteOuvre une fenêtre qui pilote un rookparcel-nox ailleurs (Fichier > Se connecter à distance... fait la même chose).
rookparcel --demo 10000Windows : ouvre la fenêtre sur un moteur simulé avec 10 000 faux torrents, pour essayer l'interface à grande échelle.
