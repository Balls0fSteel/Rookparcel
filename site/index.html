Rookparcel

A lean BitTorrent client in the spirit of µTorrent 2.2.1: small native programs, low RAM and CPU use, and an interface that stays responsive with tens of thousands of torrents.

A native Win32 GUI on Windows, a native AppKit GUI on macOS, a GTK 4 GUI on Linux and BSD, and a headless daemon, rookparcel-nox, with its own Web UI. The engine is our own Rust port of libtorrent-rasterbar 2.0.11.

News: what changed in each release.

Release candidate: pre-release software. Rookparcel works for its author but has had no wider testing yet. Settings and saved state may still change between versions, some features are only lightly tested, and nothing is code-signed.

Do not use it for torrents you care about, and not on private trackers: its client ID is not whitelisted anywhere yet. Feedback and bug reports are welcome.

The µTorrent 2.2.1 window, recreated

The Windows GUI is a faithful recreation of the µTorrent 2.2.1 main window: the category list, the torrent list with every column, the detail tabs, Preferences and the dialogs. It uses none of µTorrent's code or artwork.

On every desktop

On macOS the same main window and dialogs are a native Mac app, and on Linux and BSD they run on GTK 4, from the same frontend code as the Windows window.

Or leave the daemon running headless on a server and use it from a browser, or from either desktop GUI in remote mode.

It shares your PC

A torrent client should not be the reason a game lags or the whole computer feels slow. Rookparcel can step aside on its own, for your line and for your disks.

  • Gamer mode: keep your ping low

    Tick Keep ping low in Preferences > Bandwidth. Rookparcel finds the first router past your line and watches its ping while it downloads and uploads. As soon as the line starts to queue, it slows itself down, then speeds up again when the queue clears, so games and video calls stay responsive. There is no game list and nothing to set up.

    On a test line with half a second of buffer, the ping fell from about 480 ms to 10 ms while Rookparcel kept 80-92 % of the line's speed. It works on Windows, Linux and macOS; on BSD it goes by the delays its uTP peers measure.

  • Smart disk I/O

    Rechecks run gently: at the system's background disk priority, without pushing other programs' files out of memory, and giving way whenever another program needs the disk. Rookparcel tells SSDs, hard disks and network shares apart. It checks one torrent per drive, several drives at once, and gives a hard disk only two jobs at a time so it doesn't spend its time seeking.

    If you want it, it also slows downloads or uploads down while a disk is busy, and caps checking at a speed you choose: Preferences > Advanced > Disk I/O.

What is in it

  • A complete engine

    TCP and uTP; HTTP, HTTPS and UDP trackers; magnet links, DHT, peer exchange and local peer discovery; protocol encryption, web seeds, SOCKS and HTTP proxies, UPnP / NAT-PMP and IP filters; super-seeding, sequential download and per-torrent speed limits.

  • BitTorrent v2 and hybrid

    v2 and hybrid torrents (BEP 52): adding, downloading, seeding and creating them.

  • The whole 2.2.1 client

    Detail tabs (General, Trackers, Peers, Pieces, Files, Speed, Logger), Preferences, Add, Create and Properties, the RSS downloader, the scheduler, Auto Shutdown, the tray icon, and file and magnet associations.

  • Built for scale

    The goal is 100,000 torrents on a modest PC with an instant UI. On the author's PC the Windows GUI lists 100,000 torrents in about a second, with idle GUI CPU under 0.1 %.

  • Stays on your VPN

    Use only this network (Preferences > Connection) binds all torrent traffic to one network: any VPN adapter, one adapter by name, or an address range. Peers, the DHT, trackers and web seeds go through it and nothing else. When the VPN drops, torrents wait instead of carrying on over your normal connection, and resume by themselves when it is back.

  • Dark mode and themes

    Every program follows your system's light or dark setting. The Windows program can also be fixed to Light or Dark (Preferences > UI Settings > Theme), and every window and dialog follows. The Web UI has nine themes, among them Midnight, Slate, Solarized and High Contrast, and takes your own CSS files.

  • Headless, with a Web UI

    rookparcel-nox runs as a daemon with its own Web UI (laid out for phones too), HTTPS, and a qBittorrent-compatible Web API subset so existing tools can talk to it. It runs as a service under systemd, FreeBSD's rc.d or Windows, and as a Docker image. The Windows GUI serves the same Web UI over its own torrents, RSS Downloader included: Preferences > Web UI.

  • Search and RSS

    Search for torrents through the Prowlarr or Jackett you already run (Torznab), from either GUI or the Web UI. No search plugins of its own, so nothing breaks when a site changes. If you run neither, the search helper downloads and runs Jackett for you at a click. The RSS downloader picks up new releases by your filters.

  • Sonarr, Radarr, Prowlarr

    Add Rookparcel to them as a qBittorrent download client, against rookparcel-nox or the Windows GUI. Indexer seed goals arrive with each grab and Remove Completed works; an API key and a subnet whitelist are there if you want them.

  • Remote mode

    Either desktop GUI can drive a rookparcel-nox on another machine: File > Connect to Remote..., or start it with --remote.

  • Profiles and portable mode

    A profile is a whole Rookparcel of its own: settings, torrents, RSS feeds, ports and window. Run one that uses only your VPN beside a normal one, both at once (File > Profiles, or --profile). An empty rookparcel.ini beside the program keeps everything in that folder instead: portable mode.

  • Bring your torrents along

    Import from µTorrent or qBittorrent on the same computer. The data stays where it is; labels, file priorities, trackers and statistics come over, and Rookparcel checks the files itself before it relies on them.

  • Queue, seeding goals, watch folder

    A queue for downloads and seeds, seeding goals by ratio or time (for all torrents or one), completed downloads moved to another folder, labels, a folder watched for new .torrent files, speed limits and the weekly scheduler.

  • Big torrents stay manageable

    The Files tab shows a torrent's folders as a tree, filters thousands of files as you type, and sets a priority for a whole folder at once. The Add New Torrent dialog has the same filter.

  • Help where you need it

    A Setup Guide asks a few questions at the first start. Every setting in Preferences explains itself in a tooltip and on F1, and the user guide covers the rest, with screenshots.

  • Tells you about updates

    Rookparcel checks for a newer release and tells you. A copy installed by the Windows setup can download the new setup, check it against the release's checksums and install it; nothing is downloaded without your yes, and the check can be turned off.

  • English and 34 more languages

    Right-to-left layouts for Arabic, Hebrew and Persian included. The translations are machine-made and unreviewed, so corrections are welcome.

  • Small and self-contained

    Single self-contained executables with minimal dependencies. On Windows: statically linked, no runtime to install, and a portable mode.
