Rookparcel installieren

Von der heruntergeladenen Datei bis zum laufenden Programm, Schritt für Schritt. Die Dateien finden Sie auf der Seite Download.

Windows und macOS warnen beim ersten Start. Die Dateien von Rookparcel sind nicht codesigniert, und die Mac-App ist von Apple nicht notarisiert; das System kann deshalb nicht erkennen, von wem sie stammen. Die Schritte unten zeigen, wie die Warnung aussieht und worauf Sie klicken. Um zu prüfen, ob eine Datei die veröffentlichte ist, vergleichen Sie ihre Prüfsumme.

Windows

Windows 10 oder 11, 64 Bit. Der Installer legt einen Eintrag im Startmenü an und aktualisiert sich selbst; die ZIP-Datei installiert nichts.

Der Installer

  1. 1 Das Setup herunterladen und ausführen

    Laden Sie rookparcel-…-windows-x64-setup.exe von der Download-Seite herunter und öffnen Sie die Datei über die Downloads Ihres Browsers oder den Ordner „Downloads“.

  2. 2 SmartScreen: Weitere Informationen

    Windows zeigt „Der Computer wurde durch Windows geschützt“. Klicken Sie unter dem Text auf den kleinen Link Weitere Informationen. Erscheint kein solches Fenster, gehen Sie zum nächsten Schritt.

    Der Computer wurde durch Windows geschützt

    Microsoft Defender SmartScreen hat den Start einer unbekannten App verhindert. Weitere Informationen

    Nicht ausführen

  3. 3 SmartScreen: Trotzdem ausführen

    Das Fenster nennt nun die Datei und sagt „Unbekannter Herausgeber“. Klicken Sie auf Trotzdem ausführen.

    Der Computer wurde durch Windows geschützt

    App: rookparcel-…-setup.exe
    Herausgeber: Unbekannter Herausgeber

    Trotzdem ausführenNicht ausführen

  4. 4 Wählen, für wen es gilt

    Wählen Sie die Sprache und akzeptieren Sie die Lizenz. Auf der Seite Benutzer auswählen braucht Nur für mich installieren keine Administratorrechte. Bei Für alle Benutzer dieses Computers installieren fragt Windows nach der Erlaubnis; auch diese Abfrage sagt „Unbekannter Herausgeber“. Klicken Sie auf Ja.

    Benutzerkontensteuerung
    Möchten Sie zulassen, dass durch diese App von einem unbekannten Herausgeber Änderungen an Ihrem Gerät vorgenommen werden?

    rookparcel-…-setup.exe
    Herausgeber: Unbekannt

    JaNein

  5. 5 Komponenten, Ordner, Installieren

    Lassen Sie die Häkchen, wie sie sind, es sei denn, Sie wollen die Verknüpfung auf dem Desktop oder die Zuordnung zu .torrent-Dateien und magnet:-Links nicht. Behalten Sie den angezeigten Ordner bei und klicken Sie auf Installieren.

  6. 6 Fertig stellen

    Lassen Sie Rookparcel ausführen angehakt und klicken Sie auf Fertig stellen. Rookparcel öffnet sich mit seinem Einrichtungsassistenten. Neuere Versionen werden über diese installiert: Rookparcel weist in seiner Statusleiste darauf hin, wenn eine erschienen ist.

Die portable ZIP-Datei

  1. 1 Herunterladen und entpacken

    Laden Sie rookparcel-…-windows-x64.zip von der Download-Seite herunter. Klicken Sie die Datei mit der rechten Maustaste an, wählen Sie Alle extrahieren… und einen Ordner, in den Sie schreiben dürfen, etwa Documents\Rookparcel. Starten Sie das Programm nicht aus der ZIP-Datei heraus.

  2. 2 Optional: alles in diesem Ordner behalten

    Für den portablen Modus legen Sie vor dem ersten Start eine leere Datei namens rookparcel.ini neben rookparcel.exe an. Einstellungen und Torrents bleiben dann im Ordner; ohne die Datei kommen sie nach %APPDATA%\Rookparcel.

  3. 3 rookparcel.exe starten

    Doppelklicken Sie rookparcel.exe. Windows zeigt beim ersten Mal „Der Computer wurde durch Windows geschützt“: Klicken Sie auf Weitere Informationen und dann auf Trotzdem ausführen.

    Der Computer wurde durch Windows geschützt

    App: rookparcel.exe
    Herausgeber: Unbekannter Herausgeber

    Trotzdem ausführenNicht ausführen

  4. 4 Optional: Torrents damit öffnen

    Haken Sie die Zuordnungen für .torrent-Dateien und magnet:-Links unter Optionen > Einstellungen > Allgemein an. Sie nennen diese Kopie und funktionieren nicht mehr, wenn Sie den Ordner verschieben.

Linux

x86_64 (Intel und AMD) oder aarch64 (64-Bit-ARM); uname -m zeigt, was Sie haben. Die Befehle unten funktionieren in dem Ordner, der den Download enthält, meist ~/Downloads.

AppImage

  1. 1 Das AppImage herunterladen

    Laden Sie Rookparcel-…-x86_64.AppImage (oder -aarch64) von der Download-Seite herunter. Es braucht glibc 2.39 oder neuer: Ubuntu 24.04, Fedora 40, Debian 13 oder später.

  2. 2 Die Ausführung erlauben

    Eine heruntergeladene Datei darf erst ausgeführt werden, wenn Sie es erlauben. In einem Terminal:

    cd ~/Downloads
chmod +x Rookparcel-*.AppImage

    Oder im Dateimanager: Klicken Sie die Datei mit der rechten Maustaste an, wählen Sie Eigenschaften, Zugriffsrechte und haken Sie das Kästchen an, das die Ausführung als Programm erlaubt.

  3. 3 Starten

    Doppelklicken Sie die Datei, oder:

    ./Rookparcel-*.AppImage

  4. 4 Wenn FUSE verlangt wird

    Manche Systeme liefern FUSE 2 nicht mehr mit, und das AppImage bricht dann mit „AppImages require FUSE to run“ ab. Starten Sie es stattdessen so:

    ./Rookparcel-*.AppImage --appimage-extract-and-run

Flatpak

  1. 1 Das Bundle herunterladen

    Laden Sie Rookparcel-…-x86_64.flatpak (oder -aarch64) von der Download-Seite herunter. Ihr System braucht flatpak selbst; die meisten Desktops haben es.

  2. 2 Flathub einmalig hinzufügen

    Das Bundle enthält die Anwendung; ihre Laufzeitumgebung kommt von Flathub:

    flatpak remote-add --if-not-exists --user flathub https://dl.flathub.org/repo/flathub.flatpakrepo

  3. 3 Das Bundle installieren

    cd ~/Downloads
flatpak install --user Rookparcel-*.flatpak

    Antworten Sie mit y, wenn nach der Laufzeitumgebung gefragt wird.

  4. 4 Starten

    Rookparcel steht nun in Ihrem Anwendungsmenü, oder:

    flatpak run io.github.balls0fsteel.Rookparcel

    Es darf in Ihren Home-Ordner schreiben. Für Downloads auf einem anderen Datenträger siehe Gut zu wissen auf der Download-Seite.

Einfache Binärdateien

  1. 1 Das Archiv herunterladen

    Laden Sie rookparcel-…-linux-x86_64.tar.gz (oder -aarch64) von der Download-Seite herunter. Die Programme nutzen das GTK 4 (4.12 oder neuer) und das OpenSSL 3 Ihres Systems, wie Ubuntu 24.04 sie hat.

  2. 2 Entpacken

    cd ~/Downloads
tar -xzf rookparcel-*-linux-*.tar.gz

  3. 3 Das Fenster starten

    ./rookparcel-*-linux-*/rookparcel-gtk

    Der Ordner enthält außerdem rookparcel-nox (den Daemon), einen Desktop-Eintrag und systemd-Units.

macOS

macOS 11 Big Sur oder neuer, Apple Silicon und Intel. Apple-Menü > Über diesen Mac zeigt Ihre macOS-Version. Das Disk-Image enthält diese Schritte ebenfalls, in How to open Rookparcel.html.

macOS 15 Sequoia oder neuer

  1. 1 Die App nach „Programme“ kopieren

    Öffnen Sie Rookparcel-…-macos.dmg von der Download-Seite und ziehen Sie Rookparcel.app auf den Ordner Programme in seinem Fenster. Starten Sie die App aus „Programme“, nicht vom Disk-Image.

  2. 2 Versuchen, sie zu öffnen, dann auf „Fertig“ klicken

    Doppelklicken Sie Rookparcel in „Programme“. macOS meldet, dass es die App nicht überprüfen konnte. Klicken Sie auf Fertig, nicht auf „In den Papierkorb legen“.

    „Rookparcel“ nicht geöffnet

    Apple konnte nicht überprüfen, ob „Rookparcel“ frei von Malware ist, die Ihrem Mac schaden oder Ihre Privatsphäre gefährden könnte.

    In den Papierkorb legenFertig

  3. 3 Systemeinstellungen: Trotzdem öffnen

    Öffnen Sie im Apple-Menü die Systemeinstellungen und klicken Sie in der Seitenleiste auf Datenschutz & Sicherheit. Scrollen Sie zu Sicherheit und klicken Sie bei der Zeile zu Rookparcel auf Trotzdem öffnen. Die Schaltfläche ist nach Schritt 2 etwa eine Stunde lang da; ist sie weg, wiederholen Sie Schritt 2.

    Datenschutz & Sicherheit
    Sicherheit

    „Rookparcel“ wurde zum Schutz deines Mac blockiert.

    Trotzdem öffnen

  4. 4 Bestätigen

    Klicken Sie in der folgenden Abfrage auf Trotzdem öffnen und geben Sie dann Ihr Passwort ein oder verwenden Sie Touch ID. Rookparcel startet und öffnet sich von nun an mit einem Doppelklick.

    „Rookparcel“ öffnen?

    Apple kann nicht überprüfen, ob die App frei von Malware ist.

    Trotzdem öffnenIn den Papierkorb legenFertig

  5. 5 Lokales Netzwerk

    macOS fragt möglicherweise, ob Rookparcel Geräte in Ihrem lokalen Netzwerk finden darf. Wählen Sie Erlauben, damit Rookparcel Peers im lokalen Netz finden und einen Port an Ihrem Router öffnen kann; ohne das funktioniert es ebenfalls.

    „Rookparcel“ erlauben, Geräte in lokalen Netzwerken zu finden?
    Nicht erlaubenErlauben

macOS 11 bis 14

  1. 1 Die App nach „Programme“ kopieren

    Öffnen Sie Rookparcel-…-macos.dmg von der Download-Seite und ziehen Sie Rookparcel.app auf den Ordner Programme in seinem Fenster.

  2. 2 Control-Klick, dann „Öffnen“

    Ein Doppelklick zeigt nur eine Warnung ohne Weiterkommen. Halten Sie stattdessen in „Programme“ die Taste Control gedrückt und klicken Sie auf Rookparcel (oder klicken Sie mit der rechten Maustaste) und wählen Sie im Menü Öffnen.

  3. 3 Öffnen

    Diesmal hat die Warnung eine Schaltfläche Öffnen. Klicken Sie darauf. Rookparcel startet und öffnet sich von nun an mit einem Doppelklick.

    macOS kann den Entwickler von „Rookparcel“ nicht überprüfen. Möchten Sie das Programm wirklich öffnen?
    In den Papierkorb legenÖffnenAbbrechen

  4. 4 Wenn es keine Schaltfläche „Öffnen“ gibt

    Öffnen Sie die Systemeinstellungen > Datenschutz & Sicherheit (unter macOS 11 und 12: Sicherheit) und klicken Sie auf Trotzdem öffnen, oder nutzen Sie das Terminal.

Mit dem Terminal, oder wenn macOS „ist beschädigt“ meldet

  1. 1 Die App nach „Programme“ kopieren

    Öffnen Sie Rookparcel-…-macos.dmg und ziehen Sie Rookparcel.app auf den Ordner Programme in seinem Fenster.

  2. 2 Die Download-Markierung entfernen

    Öffnen Sie das Terminal (Programme > Dienstprogramme), fügen Sie diese Zeile ein und drücken Sie die Return-Taste:

    xattr -dr com.apple.quarantine /Applications/Rookparcel.app

    Sie entfernt die Markierung „aus dem Internet geladen“ von dieser einen App. Hat es geklappt, gibt der Befehl nichts aus.

  3. 3 Öffnen

    Doppelklicken Sie Rookparcel in „Programme“. Die App startet ohne Warnung. „Rookparcel ist beschädigt und kann nicht geöffnet werden“ ist dieselbe Sperre in anderen Worten; auch sie hebt dieser Befehl auf.
