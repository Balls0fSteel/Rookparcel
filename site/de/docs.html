Kommandozeile

Die alltäglichen Optionen. rookparcel-nox --help listet alle auf.

Kommandozeilenoptionen
BefehlWas er tut
rookparcel-nox runStartet den Daemon und setzt jeden gespeicherten Torrent fort; q und Eingabetaste oder Strg+C beenden ihn sauber.
rookparcel-nox run --webui 8080 --webui-pass PASSDasselbe, mit der Weboberfläche und der qBittorrent-kompatiblen Web-API auf 127.0.0.1:8080 (--webui ADDR:PORT für eine andere Adresse).
--webui-httpsStellt die Weboberfläche über HTTPS mit einem selbstsignierten Zertifikat bereit, das beim ersten Gebrauch erzeugt wird; --webui-cert FILE --webui-key FILE verwendet Ihres.
rookparcel-nox add file.torrent --save DIRLädt einen Torrent in DIR herunter und beendet sich, wenn er fertig ist (--seed seedet weiter, bis er gestoppt wird).
--no-update-checkStartet den Daemon ohne seine Prüfung auf eine neuere Version (ab 1.1.17; Einstellungen > Allgemein > Privatsphäre in der Weboberfläche bewirkt dasselbe).
rookparcel-nox run --verboseGibt Tracker- und Peer-Ereignisse aus, nützlich in einem Fehlerbericht.
rookparcel-nox --licenseGibt die Lizenz und die Hinweise zu Drittanbieter-Software aus.
rookparcel --remote, rookparcel-gtk --remoteÖffnet ein Fenster, das ein rookparcel-nox an anderer Stelle steuert (Datei > Mit Fernsitzung verbinden... bewirkt dasselbe).
rookparcel --demo 10000Windows: öffnet das Fenster mit einer simulierten Engine und 10.000 erfundenen Torrents, um die Oberfläche bei großer Menge auszuprobieren.
