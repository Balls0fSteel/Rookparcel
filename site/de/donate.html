Spenden

Rookparcel ist kostenlos und zeigt keine Werbung. Wenn es Ihnen gefällt, hilft eine Spende, das Projekt am Laufen zu halten.

Wege zu spenden

Mit PayPal spenden Auf GitHub unterstützen

  • PayPal: https://www.paypal.com/ncp/payment/2UDQNM8TGRUA4
    Die Spende erfolgt auf der eigenen Seite von PayPal.
  • GitHub Sponsors: https://github.com/sponsors/Balls0fSteel
    Über Ihr GitHub-Konto, auf der eigenen Seite von GitHub.

Bitte geben Sie nur, wenn Sie es sich ohne Weiteres leisten können: Ihr eigenes finanzielles Wohlergehen geht vor.

Andere Möglichkeiten zu helfen

  • Nutzen Sie Rookparcel und melden Sie, was schiefgeht, mit den Schritten, die es zeigen.
  • Bitten Sie die privaten Tracker, die Sie nutzen, die Client-ID von Rookparcel zuzulassen.
  • Erzählen Sie anderen davon.
