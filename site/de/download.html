Rookparcel herunterladen

Jede Version finden Sie auf der Releases-Seite auf GitHub.

Dies ist eine Vorabversion. Sie wurde kaum über die Rechner ihres Autors hinaus getestet, Einstellungen können sich vor 1.0 noch ändern, und sie sollte noch nicht auf privaten Trackern verwendet werden. Die Versionshinweise nennen die bekannten Einschränkungen.

Installationsanleitung Schritt für Schritt: vom Download bis zum laufenden Programm, mit den Warnungen des Systems beim ersten Start.

Welche Datei brauche ich?

  • Windows 10 oder 11 Das Setup richtet Rookparcel ein und aktualisiert es später an Ort und Stelle (ab 1.0.1). Das portable Zip installiert nichts: entpacken und starten.
  • Linux-Desktop Das AppImage bringt seine Bibliotheken mit und braucht glibc 2.35 oder neuer (Ubuntu 22.04, Debian 12, Fedora 36 oder neuer). Lieber Flatpak? Nehmen Sie das Bundle. Die reinen Binärdateien nutzen das GTK 4 und OpenSSL 3 Ihres Systems.
  • Linux-Server Das rookparcel-nox-AppImage oder rookparcel-nox aus den reinen Binärdateien, mit seiner Weboberfläche.
  • Mac Das Disk-Image, für Macs mit Apple Silicon und Intel gleichermaßen. Server können das rookparcel-nox ohne Fenster verwenden.

x64 und x86_64 sind Intel- und AMD-Prozessoren; aarch64 und arm64 sind 64-Bit-ARM.

Windows Ihr System

Windows 10 oder 11, 64 Bit (x64).

Die Dateiliste wird beim Erstellen der Website eingefügt. Jede Datei finden Sie auf der Releases-Seite auf GitHub.

SmartScreen

Die Programme sind nicht codesigniert, daher zeigt Windows SmartScreen beim ersten Mal „Der Computer wurde durch Windows geschützt“. Wählen Sie Weitere Informationen und dann Trotzdem ausführen. Die Installationsanleitung zeigt jeden Schritt.

Einstellungen und Torrents liegen in %APPDATA%\Rookparcel. Eine leere rookparcel.ini neben rookparcel.exe hält sie stattdessen in diesem Ordner, mit den Downloads in dessen Unterordner Downloads (portabler Modus, mehr). --profile work oder Datei > Profile startet ein getrenntes Rookparcel neben dem üblichen.

Linux Ihr System

x86_64 oder aarch64.

Die Dateiliste wird beim Erstellen der Website eingefügt. Jede Datei finden Sie auf der Releases-Seite auf GitHub.

Gut zu wissen

  • Einstellungen liegen in ~/.config/rookparcel/gtk, Torrents in ~/.local/share/rookparcel/gtk. Das Flatpak legt sie unter ~/.var/app/io.github.balls0fsteel.Rookparcel/ ab. Eine leere rookparcel.ini neben rookparcel-gtk oder dem .AppImage hält stattdessen alles in diesem Ordner (portabler Modus, nicht im Flatpak).
  • Das Flatpak darf in Ihren Home-Ordner schreiben, da ein Torrent-Client in die Ordner schreibt, die Sie wählen. Ein Ordner auf einem anderen Datenträger braucht flatpak override --user --filesystem=/mnt/data io.github.balls0fsteel.Rookparcel (mit Ihrem Ordner).
  • Der Daemon als systemd-Dienst: docs/DAEMON.md.

macOS Ihr System

Die Oberfläche: Apple Silicon und Intel, macOS 11 Big Sur oder neuer. Der Daemon: Apple Silicon (macOS 11 oder neuer) und Intel (macOS 10.14 oder neuer).

Die Dateiliste wird beim Erstellen der Website eingefügt. Jede Datei finden Sie auf der Releases-Seite auf GitHub.

Gatekeeper

Rookparcel.app ist ad hoc signiert und nicht notarisiert, daher weist Gatekeeper sie beim ersten Mal ab („Nicht geöffnet“ oder „kann nicht geöffnet werden, da der Entwickler nicht überprüft werden kann“). Erlauben Sie sie einmal; die Installationsanleitung zeigt jeden Schritt, und das Disk-Image enthält sie in How to open Rookparcel.html.

  • macOS 15 Sequoia und neuer: Versuchen Sie, die App zu öffnen, und klicken Sie auf Fertig. Öffnen Sie dann Systemeinstellungen > Datenschutz & Sicherheit, klicken Sie unter „Sicherheit“ auf Trotzdem öffnen und bestätigen Sie.
  • macOS 11 bis 14: Klicken Sie die App mit gedrückter Control-Taste (oder mit der rechten Maustaste) an, wählen Sie Öffnen und dann noch einmal Öffnen.

Oder, auch wenn macOS sagt, die App „ist beschädigt“, entfernen Sie das Quarantäne-Flag, nachdem Sie sie nach Programme kopiert haben:

xattr -dr com.apple.quarantine /Applications/Rookparcel.app

Rookparcel.app ist ein natives macOS-Programm, eine Datei für Apple Silicon und Intel. Einstellungen und Torrents liegen in ~/Library/Application Support/Rookparcel/mac. Wenn Sie von der älteren GTK-Version der App kommen, wird deren Ordner gtk dort beim ersten Start zu mac, sodass Einstellungen und Torrents übernommen werden.

Ohne Fenster: rookparcel-nox

Der Daemon steckt im Windows-Zip, in den reinen Linux-Binärdateien, im eigenen Linux-AppImage und im macOS-Tarball. Starten Sie ihn mit der Weboberfläche auf Port 8080:

rookparcel-nox run --webui 8080 --webui-pass PASS

Öffnen Sie dann http://127.0.0.1:8080 auf demselben Rechner und melden Sie sich als admin an. Ohne --webui-pass gibt er beim ersten Start ein vorläufiges Passwort aus; legen Sie eines unter Einstellungen > Web-UI fest. Derselbe Port stellt eine qBittorrent-kompatible Web-API für vorhandene Werkzeuge bereit.

Von anderen Rechnern aus: Geben Sie eine Adresse an, etwa --webui 0.0.0.0:8443, und fügen Sie --webui-https hinzu, damit das Passwort nicht im Klartext übertragen wird (beim ersten Gebrauch wird ein selbstsigniertes Zertifikat erzeugt). rookparcel-nox add file.torrent --save DIR fügt einen Torrent hinzu. Den Betrieb als Dienst (systemd, FreeBSD rc.d, ein Windows-Dienst, --daemon) beschreibt docs/DAEMON.md.

Einen Download prüfen

Jede Version auf der Releases-Seite hat eine Datei SHA256SUMS.

Mit SHA256SUMS im selben Ordner wie Ihr Download:

Linux

sha256sum -c --ignore-missing SHA256SUMS

macOS

shasum -a 256 Rookparcel-*.dmg

Vergleichen Sie das Ergebnis mit der Zeile der Datei in SHA256SUMS.

Windows (PowerShell)

Get-FileHash .\rookparcel-*.zip

Vergleichen Sie den Hash mit der Zeile der Datei in SHA256SUMS (Groß- und Kleinschreibung spielt keine Rolle).

Aktualisieren

Rookparcel aktualisiert sich nicht selbst. Ab 1.0.1 zeigen die Oberflächen in ihrer Statusleiste einen kurzen Hinweis, wenn eine neuere Version erschienen ist (ab 1.1.17 gibt rookparcel-nox eine Zeile aus und zeigt in seiner Weboberfläche einen Link); laden Sie diese von dieser Seite oder von GitHub herunter. Was sich geändert hat, steht auf der News-Seite. Die Prüfung liest eine kleine Datei von dieser Website und lässt sich abschalten (was sie sendet).

  • Setup: Führen Sie das neue Setup aus. Es aktualisiert die installierte Kopie an Ort und Stelle.
  • Portables Zip: Beenden Sie Rookparcel und ersetzen Sie dann rookparcel.exe und rookparcel-nox.exe von Hand durch die neuen. Ihre Einstellungen bleiben, wo sie sind (im portablen Modus lassen Sie den Rest dieses Ordners, wie er ist).
  • AppImage: Ersetzen Sie die alte Datei durch die neue.
  • Flatpak: Installieren Sie das neue Bundle über das alte mit flatpak install --user --reinstall und seinem Dateinamen.
  • Reine Binärdateien und der macOS-Tarball: Entpacken Sie das neue Archiv und nutzen Sie dessen Programme.
  • macOS: Ziehen Sie die neue Rookparcel.app nach Programme und ersetzen Sie die alte.

Ältere Versionen und jede Vorabversion finden Sie auf der Releases-Seite. Wenn Sie Rookparcel selbst bauen möchten, lesen Sie Building in der README.
