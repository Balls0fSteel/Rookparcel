Línea de comandos

Las opciones de uso diario. rookparcel-nox --help las enumera todas.

Opciones de la línea de comandos
ComandoQué hace
rookparcel-nox runInicia el demonio y reanuda todos los torrents guardados; q y Intro, o Ctrl+C, lo detienen de forma ordenada.
rookparcel-nox run --webui 8080 --webui-pass PASSLo mismo, con la interfaz web y la API web compatible con qBittorrent en 127.0.0.1:8080 (--webui ADDR:PORT para otra dirección).
--webui-httpsOfrece la interfaz web por HTTPS con un certificado autofirmado que se crea en el primer uso; --webui-cert FILE --webui-key FILE usa el suyo.
rookparcel-nox add file.torrent --save DIRDescarga un torrent en DIR y termina cuando acaba (--seed sigue sembrando hasta que se detenga).
--no-update-checkInicia el demonio sin su comprobación de una versión más reciente (1.1.17 y posteriores; Preferencias > General > Privacidad de la interfaz web hace lo mismo).
rookparcel-nox run --verboseImprime los eventos de trackers y pares, útil en un informe de errores.
rookparcel-nox --licenseImprime la licencia y los avisos de terceros.
rookparcel --remote, rookparcel-gtk --remoteAbre una ventana que maneja un rookparcel-nox situado en otro lugar (Archivo > Conectar en remoto... hace lo mismo).
rookparcel --demo 10000Windows: abre la ventana sobre un motor simulado con 10 000 torrents falsos, para probar la interfaz a gran escala.
